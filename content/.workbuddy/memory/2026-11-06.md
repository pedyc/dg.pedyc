**关键技术发现（下次别踩）**：Obsidian Excalidraw 插件的 `compressed-json` **不是 pako/zlib deflate**，是 **LZString compressToBase64**。用 `zlib.decompress` 会报 `incorrect header check`。已实现 Python 版 compress/decompress（16 位分支要处理：字符 >255 走 16 位编码，最终串需按 UTF-16 处理代理对）。

**可复现的验证方法**（比"看起来对"强得多）：用自写编码器把旧图的解压结果重新压缩，与旧文件原文**逐字符比对**，23040 字符完全相同 → 编码器与插件一致。此后任何脚本生成的 excalidraw 都能用这一招自证。

**布局校验**：元素 id 唯一、绑定双向成立、卡片不重叠 / 不越出带、说明文字不溢出卡片底部；另用 Pillow 按同一份 JSON 渲染预览图人眼复核一次，发现第一组卡片比别组高而内容最少，收 300→272 后重出。
