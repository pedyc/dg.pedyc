## 快速开始

本库是基于 Obsidian + Quartz 的个人数字花园，集成 LLM Wiki 维护系统。3 分钟上手。

### Step 1：创建笔记

使用 Templater 插件创建笔记，选择模板类型：

| 想记录什么 | 选择模板 | 自动进入目录 |
|-----------|----------|--------------|
| 闪念/洞察 | `template_atomic.md` | 30-Zettelkasten |
| 概念总览 | `template_concept.md` | 40-RESOURCES |
| 领域入口 | `template_moc.md` | 40-RESOURCES |
| 操作流程 | `template_sop.md` | 40-RESOURCES |
| 术语定义 | `template_term.md` | 40-RESOURCES |
| 项目笔记 | `template_project.md` | 10-PROJECTS |
| 领域笔记 | `template_area.md` | 20-AREAS |
| 博客文章 | `template_article.md` | 60-BLOGS |

### Step 2：填写 frontmatter

```yaml
---
uid: <自动生成>
title: <笔记标题>
aliases: [<类型前缀-标题>]  # 如 C-闭包
tags: [<父/子>]
date-created: <自动>
date-modified: <自动>
status: fleeting
content-type: <笔记类型>
---
```

### Step 3：理解状态流转

```bash
fleeting → cultivating → active → completed → archived
  ↓           ↓            ↓         ↓          ↓
 闪念/草稿    培育中       活跃      已完成     已归档
```

- **fleeting**：刚捕获的想法
- **cultivating**：持续补充内容
- **active**：作为主力引用
- **completed**：内容成熟但不再主动维护
- **archived**：终态（atomic 除外）

### Step 4：引用而非复制

```markdown
<!-- 错误：复制内容 -->
闭包是指...

<!-- 正确：引用链接 -->
[[闭包]] 是一个核心概念...

<!-- atomic 用陈述句 -->
[[闭包的本质是函数执行时创建的作用域链]]
```

### Step 5：使用 aliases 前缀检索

| 前缀 | 类型 | 示例 |
|------|------|------|
| P- | project | `P-求职` |
| A- | area | `A-人工智能` |
| Q- | question | `Q-如何学习编程` |
| MOC- | moc | `MOC-前端知识地图` |
| SOP- | sop | `SOP-周回顾` |
| T- | term | `T-TCP` |
| C- | concept | `C-闭包` |
| VS- | comparison | `VS-React vs Vue` |
| R- | record | `R-俄乌冲突` |

> **原则**：前缀放 aliases，文件名用纯标题，正文引用更通顺。
