## 目录结构

```bash
content/
├── 00-META/           # 系统元数据（含 Truth/ 真值、架构、规范、索引）
├── 10-PROJECTS/       # project（面向 PARA 项目，有明确目标/截止日期）
├── 20-AREAS/          # area（面向 PARA 领域，需持续关注）
├── 30-RESOURCES/      # 整合笔记（wiki 层，LLM 维护）
├── 40-ARCHIVE/        # 归档（已完成/过时/孤立节点）
├── 50-ZETTELCASTEN/   # atomic（原创洞见，source of truth）
├── 60-BLOGS/          # article（博客文章）
├── 80-PRIVATE/        # 私有内容（敏感信息、API keys 等）
├── 90-DIARY/          # diary（日记，时间序列）
└── 99-ASSETS/         # 额外资源（插件配置、附件等）
```

## 目录与 content-type 映射

| 目录 | 存放内容 | content-type | 决定方式 |
|------|---------|-------------|---------|
| `00-META/` | 系统元数据（真值、架构、规范、索引、日志） | — | 位置（系统固定） |
| `10-PROJECTS/` | 项目笔记 | `project` | 位置决定 |
| `20-AREAS/` | 领域笔记 | `area` | 位置决定 |
| `30-RESOURCES/` | 整合笔记 | `concept`、`moc`、`sop`、`question`、`term`、`comparison`、`record`、`roadmap`、`person` | content-type 决定 |
| `40-ARCHIVE/` | 归档内容 | — | 状态决定 |
| `50-ZETTELCASTEN/` | 原子笔记 | `atomic`（唯一） | content-type 决定 |
| `60-BLOGS/` | 博客文章 | `article` | 位置决定 |
| `80-PRIVATE/` | 私有内容 | — | 位置（系统固定） |
| `90-DIARY/` | 日记 | `diary` | 位置决定 |
| `99-ASSETS/` | 额外资源（附件、插件配置） | — | 位置（系统固定） |

## 决定规则

- **特定型**（由物理位置决定）：`project` → 10-PROJECTS，`area` → 20-AREAS，`article` → 60-BLOGS，`diary` → 90-DIARY
- **通用型**（由 content-type 决定）：`atomic` → 50-ZETTELCASTEN，其余（concept/moc/sop/question/term/comparison/record/roadmap/person）→ 30-RESOURCES
- **状态决定**：`40-ARCHIVE/` 由笔记归档状态决定，非新建目录

## 维护归属

| 目录 | 维护方 |
|------|--------|
| 00-META、10-PROJECTS、50-ZETTELCASTEN、90-DIARY | 人类维护 |
| 30-RESOURCES、40-ARCHIVE、60-BLOGS、99-ASSETS | AI 生成/维护 |

## 00-META 内部结构

```bash
00-META/
├── Truth/            # 真值表（全库唯一权威定义，本文件所在）
├── Architecture/     # 架构设计、子系统概述、设计原则
├── Decisions/        # ADR 架构决策记录
├── Faq/             # 常见问题与设计问题汇总
├── Guide/           # 指南、快速开始（引用真值文件）
├── Index/           # 导航索引、领域索引、看板索引
├── Log/             # 操作日志（wiki-log、suggest-log）
├── Specification/   # LLM 工作流规则（ingest/lint/query/sync/anki）
└── _resources/      # 架构图等资源文件
```
