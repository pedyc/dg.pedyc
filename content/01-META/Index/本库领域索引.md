## 本库领域索引

这是**花园的门**：19 个责任领域按层级排开，每个进去都是一条可走的路径。

> [!tip] 与 [[wiki-index]] 的分工
> 找一篇已经知道名字的东西 → [[wiki-index]]（1200 条名册，查得到但走不进去）。
> 从零开始逛 → 这张表。分工的道理见 [[本库指南#两个入口]]。

### 自我与知识

- [[个人成长]] — 认知提升与自我管理的责任领域；习惯、精力、身体由子领域承载
	- [[健康管理]] — 身体健康与心理健康的综合领域；精力管理归时间管理
	- [[时间管理]] — 时间管理领域知识索引
	- [[求职]] — 求职备战领域：面试题库、算法训练、简历与职业规划
- [[知识管理]] — 捕捉、组织、提炼和应用知识，构建第二大脑
	- [[视觉思维]] — 通过图形、图表等视觉化方式辅助思考和表达信息的思维方式

### 技术

- [[人工智能]] — 理解和应用大语言模型与智能体生态，提升开发生产力
- [[前端开发]] — 创建用户交互界面的技术领域，关注体验、性能与兼容性
	- [[JavaScript]] — 核心概念、运行机制、生态工具
	- [[TypeScript]] — JavaScript 的超集，加了类型系统
	- [[CSS]] — Web 的表现层语言，层叠与继承决定渲染方式
	- [[浏览器]] — 前端开发的宿主环境，多进程架构加渲染引擎与 JS 引擎
	- [[前端工程]] — 构建编译、质量保障、CI/CD 与监控治理
	- [[React]] — 组件化与 Virtual DOM
	- [[Vue]] — 渐进式框架，数据驱动与组件化
	- [[Angular]] — Google 维护的企业级全栈方案
	- [[ThreeJS]] — 浏览器里的 3D 图形
	- [[Web安全]] — 保护 Web 应用免受常见攻击的知识体系

> 前端开发的上游是 [[软件工程]]（MOC，不是 area）——「工程怎么组织」比「前端怎么做」更一般。
