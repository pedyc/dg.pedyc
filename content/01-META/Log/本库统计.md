### 口径

- **原子笔记** = `50-ZETTELCASTEN/` 下全部笔记。按目录判而非按 `content-type` 判：该目录是单形态容器，里面有字段留空的照样是原子笔记，按字段判会静默漏掉。
- **全部笔记** = 库内 md 减去「是文件但不是笔记」的工件（基线表末行可核对）：归档 88、模板 17、脚本 1、画布源文件 12、系统资产 44、回收站 9、根目录 CLAUDE.md 1、本页自身（统计页） 1。口径要变应该改本脚本的 `EXCLUDE`，而不是在某篇笔记里另算一遍。
- **散落原子笔记**：下列笔记标了 `content-type: atomic` 但不在原子目录，未计入分子。INBOX 里的属「待迁出」，日记里的其实是日记正文中的观点。

  - 笔记原子化的拆分标准是用一句话能陈述一个观点
  - 笔记处理应在使用时而非定期

### 引用本页

三种粒度，按需要选。引用数字时把日期一起带上，否则半年后没人知道是哪一代。

**① 句子里嵌一个数**——实时计算、不带日期。本库已开内联 dataviewjs（`enableInlineDataviewJs`），把这行直接写进正文：

```markdown
这库有 `$= dv.pages('"50-ZETTELCASTEN"').length` 篇原子笔记。
```

**② 单独一段嵌一个指标**——取快照值，带生成日期。下面三段带块 ID，重跑后 ID 不变，别处写 `![[本库统计#^atom-count]]` 就只嵌这一段，不牵动整页：

原子笔记 **226** 篇 ^atom-count

全部笔记 **1219** 篇 ^total-count

原子笔记占比 **18.5%** ^atom-ratio

**③ 整张基线表**——六个指标一起，仍然不是整页：`![[本库统计#当前基线]]`

### 重新生成

```bash
python _scripts/stats.py            # 覆盖基线 + 追加历史
python _scripts/stats.py --dry-run  # 只看数字，不写文件
```
