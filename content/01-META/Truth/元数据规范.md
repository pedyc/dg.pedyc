## 各类型专属字段

> 本表是**各 content-type 特有 frontmatter 字段的唯一定义**。`笔记类型规范` 只声明「某类型有专属字段」，具体字段定义以本表为准。

### project（项目笔记）

| 字段 | 用途 | 可选值 |
|------|------|--------|
| `consequence` | 重要程度 | 1~10 |
| `urgency` | 紧急程度 | 1~10 |
| `energy-type` | 精力类型 | 💡 创意 / ⚡ 能量 / 🔄 常规 / 🏃 运动 |
| `expire` | 截止日期 | 日期 |

> [!important] `quadrant` 不是存储字段
> 四象限位置由 `consequence` 与 `urgency` 派生（重要 ≥7 且紧急 ≥7 为 Q1，重要 ≥7 但紧急 <7 为 Q2，以此类推），**不由人工填写**。原 `quadrant:` 字段已于 2026-10-23 从模板与本文移除：它是前两个字段的函数，三处手工维护必然产生不一致。实测依据：`10-PROJECTS` 内 `consequence` / `urgency` 各填 2 篇，`quadrant` 为 0 篇。
>
> 需要看象限分布时，在 `.base` 里用 formula 计算，不要在笔记里落库。

## status：笔记状态

> 流转方向：**单向不可逆**（atomic 例外：永不复用）

| 状态 | 含义 | 典型触发条件 |
|:---|:---|:---|
| `fleeting` | 闪念/草稿 | 刚捕获的原始想法，尚未加工 |
| `active` | 在用 | 已加工，仍在被引用或维护 |
| `archived` | 已归档 | 终态，不再维护 |

```bash
fleeting → active → archived
  ↓          ↓         ↓
闪念/草稿    在用     已归档
                       ↑
                  atomic 除外
```

> [!important] 2026-10-23 由 5 值收窄为 3 值
> 原 `cultivating`（培育中）与 `completed`（已完成）已并入 `active`，共改写 344 篇笔记。
> - `cultivating` 与 `active` 的边界靠主观判断，实测两者长期各占约三分之一，说明这条分界没有被稳定使用
> - `completed` 表达的是「内容成熟」而非「生命周期结束」，与 `archived` 语义重叠
>
> 三值模型 = **草稿 / 在用 / 退役**，判断成本最低。代价是 `active` 占约八成，字段区分度下降；需要判断「是否陈旧」时应改用 `date-modified`。40-ARCHIVE 按免维护原则未参与改写。

## 按 content-type 的归档语义

| content-type | completed 语义 | 归档触发条件 |
|:---|:---|:---|
| `atomic` | 洞察完成 | ⚠️ 几乎不归档——洞察是资产，永不过期 |
| `concept` | 概念理解完成 | 版本过时但笔记未更新 |
| `term` | 定义完成 | 定义被证伪或被新版本替代 |
| `roadmap` | 版本覆盖完成 | 新版本已发布但笔记未更新 |
| `sop` | 流程验证完成 | 技术栈变更导致流程失效 |
| `area` | 领域探索完成 | 放弃该领域的学习/关注 |
| `moc` | 索引整理完成 | 主题已放弃，无导航价值 |

## 归档的两层机制

| 机制 | 适用场景 | 操作 |
|:---|:---|:---|
| `status: archived` | 笔记仍有效但不想维护 | 原目录不动，仅改 status |
| 移入 `40-ARCHIVE/` | 明确过时/错误/长期孤立且无保留价值 | 物理移动到归档目录 |

> [!warning]
> **Zettelkasten 不删除原则**：atomic 笔记永不被删除；其他类型笔记过时/孤立时归档而非删除。

## 归档判断决策树

```bash
笔记不更新了？
├── 内容完善 + 仍被引用 + 版本未过时
│   └── → status: completed（原目录不动）
├── 版本已更新但笔记未更新
│   └── → status: archived 或 移入 40-ARCHIVE/
├── 入链=0 + 从未被引用 + 无孤立价值
│   └── → 移入 40-ARCHIVE/
└── atomic 类型
    └── → 永不归档（洞察是资产）
```
