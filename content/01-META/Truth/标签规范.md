## 格式

```bash
#父标签/子标签
```

## 推荐标签体系

| 父标签 | 子标签 |
|--------|--------|
| `#知识管理` | 方法论、工具、工作流、心智模型 |
| `#人工智能` | AI 助手、提示词、Agent |
| `#前端开发` | JavaScript、React、工程化、CSS |
| `#个人成长` | 健康、时间管理、习惯 |
| `#工具` | AI、编辑器、效率 |
| `#方法论` | PARA、卡片盒、费曼技巧 |
| `#认知科学` | 心理学、记忆、学习 |

## 原则

- **content-type ≠ tags**
  - content-type：决定笔记形式（atomic/concept/sop/term），对应模板
  - tags：描述笔记主题，用于横向分类
- 主要用于话题（Topic）和媒介（Medium）
- 无数量限制
- 无特殊含义标签
