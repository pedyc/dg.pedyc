## 目标

> 不做会怎样：目标岗位的面试会直接问「你做过什么 Agent 系统」。答不上来，就停在「会写前端」这一侧——缺的不是一门知识，是一个能被别人验证的工程成果。

**Outcome**：具备申请 Agent / AI Agent Engineering 相关岗位的能力，形成可展示、可验证的工程成果，并通过实际求职检验岗位匹配情况。

**不做**：

- 不以「把下面的专项全部学完」为开工条件。简历、项目成果与基础面试准备到可以尝试的程度，就进入真实招聘流程，按反馈继续调整。
- 不以技术名词的堆叠或功能数量判断项目质量；说清取舍与失败模式才算数。
- 不另列一份「成功标准」。KR 就是成功标准——同一层两份清单必然漂移（原七条已并入下面的 KR，2026-11-10）。
