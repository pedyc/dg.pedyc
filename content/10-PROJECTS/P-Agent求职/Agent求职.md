## 背景

随着 LLM 应用的发展，Agent 逐渐成为软件工程中的一个重要技术方向。

作为前端工程师，希望在现有软件工程能力的基础上，系统学习 Agent 的核心原理与工程实践，探索前端与 Agent Engineering 相结合的职业发展方向。

本项目不以单纯学习知识为目标，而是通过系统学习、专项实践、完整项目开发和真实求职反馈，逐步建立能够应用于实际工程场景的 Agent 开发能力。

采用「Project → KR → 专项 → 行动与产出」的方式组织项目。

---

## 核心目标

**Outcome**：具备申请 Agent / AI Agent Engineering 相关岗位的能力，形成可展示、可验证的工程成果，并通过实际求职检验自己的岗位匹配情况。

**成功标准**：

- 能够解释 Agent 的核心概念、架构、运行机制及主要技术方向。
- 能够独立设计和实现具有明确使用场景的 Agent 系统。
- 能够理解并处理 Agent 工程中的工具调用、上下文管理、可靠性、评估和安全等问题。
- 完成至少一个具有明确价值、可以运行和演示的 Agent 项目。
- 形成能够展示个人工程能力的代码仓库、技术文档和项目 Demo。
- 完成针对目标岗位的简历、作品集和面试准备。
- 开始实际投递，并根据岗位要求、面试表现和招聘反馈调整求职策略。

### KR1：建立 Agent 核心知识体系与工程实践能力（40%）

**目标：**

理解 Agent 的基本组成、运行机制和主要技术方向，并能够通过编码、实验和技术分析，将知识转化为实际工程能力。

不仅能够解释 Agent 的工作原理，还能够分析 Agent 系统的设计取舍、失败模式和工程限制。

**专项：**

- [[Agent学习专项-基本概念与架构]]：Agent 基本概念与架构
- [[Agent学习专项-LLM与ToolCalling]]：理解模型与工具之间的交互机制，并完成工具调用实验。
- [[Agent学习专项-AgentLoop]]：理解 Agent 的循环执行机制，并实现最小 Agent Loop。
- [[Agent学习专项-ContextEngineering]]：理解上下文组织、信息选择和上下文限制。
- [[Agent学习专项-AgentMemory]]：理解 Agent 状态与记忆机制，并完成简单实践。
- [[Agent学习专项-Planning与Workflow]]：研究任务规划、工作流及其适用场景。
- [[Agent实践专项-RAG]]：理解并实现检索增强生成流程。
- [[Agent实践专项-MCP]]：理解 MCP 架构并完成基本交互实验。
- [[Agent实践专项-MultiAgent]]：研究多 Agent 协作模式及其工程成本。
- [[Agent实践专项-AgentEvaluation]]：建立基本评估案例和评估指标。
- [[Agent实践专项-AgentReliability]]：研究超时、重试、失败恢复等可靠性问题。
- [[Agent实践专项-AgentObservability]]：实现执行记录与关键事件追踪。
- [[Agent实践专项-AgentHarness]]：研究 Harness 的职责边界、执行约束与独立验证机制。

### KR2：形成可展示、可验证的 Agent 工程项目成果（35%）

**目标：**

通过完整项目证明自己具备 Agent 工程实践能力。

能够从实际问题出发完成需求分析、架构设计、核心功能实现、测试验证和项目交付，并清楚解释关键技术决策。

**专项：**

- [[Agent项目专项-岗位与项目需求分析]]：结合目标岗位和个人技术方向，识别适合开展的项目问题。
- [[Agent项目专项-项目选题与需求分析]]：明确项目目标、用户场景、核心需求和范围边界。
- [[Agent项目专项-架构设计]]：完成系统架构、模块职责、数据流和关键技术选择。
- [[Agent项目专项-MVP实现]]：实现最小可运行版本，验证核心场景。
- [[Agent项目专项-Agent核心能力实现]]：实现项目所需的工具调用、上下文管理、任务编排等能力。
- [[Agent项目专项-测试与评估]]：建立测试案例，验证核心行为并分析失败情况。
- [[Agent项目专项-工程化完善]]：处理错误、状态管理、日志、配置和必要的安全边界。
- [[Agent项目专项-文档与Demo]]：完成安装说明、架构文档、使用说明和演示。
- [[Agent项目专项-项目复盘与技术表达]]：总结技术决策、工程难点、验证结果和改进方向。

**项目原则：**

优先选择能够体现 Agent 工程能力、具有明确使用场景且可以实际验证的项目。

不以堆叠技术名词或增加不必要的功能作为项目质量的判断标准。

---

### KR3：完成 Agent 求职准备并通过真实反馈持续调整（25%）

**目标：**

将知识积累和工程成果转化为求职竞争力，明确目标岗位与能力差距，完成求职材料和面试准备，并通过实际投递检验自己的岗位匹配情况。

**专项：**

- [[Agent求职专项-岗位调研与能力差距分析]]：收集目标岗位要求，建立岗位能力矩阵，识别已有优势与待补足能力。
- [[Agent求职专项-简历与项目表达]]：形成针对目标岗位的简历，清楚描述项目贡献、技术决策和实际成果。
- [[Agent求职专项-Agent技术面试]]：准备 Agent 核心概念、架构、工具调用、RAG、评估和可靠性等技术问题。
- [[Agent求职专项-系统设计面试]]：练习 Agent 场景下的需求分析、架构设计和技术取舍。
- [[Agent求职专项-项目讲解]]：围绕项目背景、设计方案、工程难点、验证结果和改进方向进行讲解。
- [[Agent求职专项-模拟面试与反馈改进]]：通过模拟面试识别表达与知识方面的不足。
- [[Agent求职专项-岗位筛选与投递]]：建立岗位跟踪记录，开展实际投递。
- [[Agent求职专项-求职反馈分析]]：分析投递和面试反馈，调整学习重点、项目表达及岗位范围。

**求职原则：**

不要求所有学习专项完成后才开始投递。

当简历、项目成果和基础面试准备达到可以尝试的程度时，就可以进入真实招聘流程，并根据反馈继续改进。
