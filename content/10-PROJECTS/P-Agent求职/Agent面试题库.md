以下按 **AI/LLM Agent 方向**整理。每题后括号是面试官通常想听的考察点。如果你说的是 Java Agent、监控 Agent 或别的方向，我也可以另出一份。

## 一、基础概念

1. 什么是 LLM Agent？和 Chatbot、RAG、Workflow 的区别是什么？（自主性、工具调用、循环决策、环境反馈）
2. Agent 的核心组件有哪些？（模型、规划、记忆、工具、执行器、环境、评估）
3. 什么任务适合 Agent，什么任务不适合？（动态性、不确定性、可靠性、成本）
4. Agent 和固定 Workflow 如何选型？（可控性 vs 灵活性）
5. 解释 ReAct、Plan-and-Execute、Reflexion 的区别和适用场景。
6. Function Calling 和 ReAct 的关系与区别？
7. 什么是 MCP？它解决什么问题？
8. Agent 的"自主性"如何分级？L0-L4 大致怎么划分？

## 二、规划与推理

9. ReAct 的 Thought-Action-Observation 循环如何工作？什么时候终止？
10. 如何做任务分解？层级规划、动态重规划怎么做？
11. 什么情况下触发重新规划？如何避免频繁重规划？
12. 如何防止 Agent 无限循环、重复调用工具、陷入死胡同？
13. Tree of Thoughts、LATS 适合什么任务？代价是什么？
14. Reflexion 自我反思什么时候有效？如何避免过度反思？
15. 用户目标模糊时，Agent 应该主动澄清还是先猜测？策略是什么？
16. 如何让 Agent 在长任务中保持目标一致性？

## 三、记忆与上下文

17. Agent 记忆有哪些类型？短期、长期、情景、语义、程序性记忆。
18. 长上下文如何压缩？摘要、检索、分层记忆、遗忘策略怎么选？
19. 长期记忆如何写入、检索、更新和删除？冲突怎么解决？
20. 多轮对话状态如何表示？状态机、槽位、摘要、向量记忆？
21. 上下文工程的关键要素有哪些？系统提示、工具描述、示例、状态摘要。
22. 如何防止上下文污染和错误记忆被反复放大？
23. 记忆检索召回不准时怎么排查？

## 四、工具与执行

24. 设计一个好工具的原则是什么？名称、描述、参数 schema、错误信息、粒度。
25. Agent 选错工具怎么办？工具检索、分类、few-shot、约束、校验。
26. 工具调用失败、超时、部分成功分别怎么处理？
27. 如何保证工具调用幂等、安全、可审计？
28. 如何验证工具返回结果？Schema 校验、业务规则、交叉验证。
29. 浏览器 Agent 如何稳定操作页面？选择器、弹窗、等待、重试、截图验证。
30. 编码 Agent 如何安全读仓库、改代码、跑测试？沙箱、权限、diff 审核。
31. 如何做工具网关？鉴权、限流、审计、统一错误码。

## 五、多智能体

32. 多智能体常见协作模式有哪些？Supervisor、辩论、流水线、群体协作。
33. 多智能体什么时候不如单智能体？通信成本、错误传播、状态不一致。
34. 如何设计 Supervisor 路由？路由错了怎么兜底？
35. 多智能体之间如何共享状态和通信？消息、黑板、共享内存？
36. 如何避免多智能体无限对话和错误级联？
37. 多智能体系统如何评估？只看最终结果还是也看协作过程？

## 六、评估与调试

38. 如何评估一个 Agent？任务成功率、步骤效率、工具准确率、成本、延迟、安全性。
39. 如何构建 Agent 评测集？任务、环境、初始状态、成功标准、随机性。
40. 如何调试 Agent 失败？Trace、日志、回放、状态快照、可视化。
41. 如何做 A/B 测试和灰度上线？
42. 如何评估幻觉和工具结果忠实度？
43. 常见 Agent 失败模式有哪些？规划错误、工具误用、上下文丢失、级联错误、奖励黑客。
44. 如果成功率从 80% 降到 50%，你怎么排查？

## 七、安全与对齐

45. 提示注入有哪些类型？直接注入、间接注入怎么防？
46. 如何防止数据泄露、越权和 PII 外泄？
47. 权限与人类审批如何设计？风险分级、确认、审计。
48. 如何防止工具滥用和奖励黑客？
49. 多租户 Agent 如何做隔离？
50. 如何让 Agent 遵守业务政策？规则引擎 + LLM 怎么配合？

## 八、工程与系统设计

51. 设计一个生产级 Agent 架构：API、编排、记忆、工具网关、队列、可观测性。
52. 如何优化 Agent 成本和延迟？缓存、模型路由、并行工具、提前退出、小模型。
53. 长任务如何做检查点、持久化、恢复？
54. 并发、队列、幂等、重试怎么设计？
55. 可观测性要记录哪些字段？Trace ID、步骤、工具参数、结果、token、耗时、错误。
56. LangChain、LangGraph、AutoGen、CrewAI 如何选型？关注状态、控制、可观测性。
57. 设计一个客服 Agent，能查订单、退款、升级人工。
58. 设计一个研究 Agent，能搜索、阅读、引用、避免幻觉。
59. 设计一个编码 Agent，能读仓库、改代码、跑测试、提交 PR。
60. 编码题：实现一个带最大步数、重复动作检测、超时控制的 ReAct Executor。
61. 编码题：实现工具注册中心和 JSON Schema 参数校验。
62. 编码题：实现记忆检索 + 摘要压缩 + 冲突处理。
63. 编码题：实现多智能体 Supervisor 路由。

## 高频必问 10 题

1. ReAct 流程和终止条件。
2. Agent 和 Workflow 如何选型。
3. 如何防止无限循环和工具误用。
4. 短期/长期记忆怎么设计。
5. Function Calling 和 ReAct 区别。
6. 如何评估 Agent。
7. 提示注入怎么防。
8. 如何控制成本、延迟和可靠性。
9. 设计一个客服/研究/编码 Agent。
10. 成功率下降如何系统排查。
