## 问题

Context 中出现冲突信息会怎样？

## 回答

Context 中出现冲突信息，本质上是：

> **模型面对多个互斥的"事实"，但不知道哪个可信、哪个优先。**

这不会让 LLM 停下来，而会让它在冲突信息上继续推理，结果通常比"缺信息"更隐蔽、更危险。

---

### 1. 模型会随机选一个，或混合两者

LLM 没有内置的"事实裁决器"。
当两条信息冲突时，它可能：

- 选先出现的
- 选后出现的
- 选更常见的
- 把两者混合，产生第三种错误结论

例如：

```text
文档：项目使用 React
用户：项目使用 Vue
```

模型可能输出：

```text
在 React 组件中……同时确保 Vue 的响应式……
```

**后果：**

- 方案自相矛盾
- 代码无法运行
- 用户难以理解模型为什么这么做

---

### 2. 模型会自信地采用错误版本

冲突信息中如果包含过期信息，模型可能恰好选中它。

例如：

```text
旧文档：API 路径是 /api/v1/login
最新代码：API 路径是 /api/v2/login
```

模型若采用旧路径：

- 请求失败
- 调试方向错误
- 可能反复修改无关代码

**后果：**

- 基于过期信息推理
- 重复已废弃方案
- 浪费多轮循环

---

### 3. 多轮 Agent 循环中，冲突会累积放大

第一轮选错版本后，后续 Tool Call 都会围绕错误版本展开。

```text
冲突：React / Vue
     ↓
模型选 React
     ↓
读取 React 文件
     ↓
修改 React 组件
     ↓
测试失败
     ↓
继续在 React 方向排查
```

**后果：**

- 错误路径越走越深
- 上下文越来越混乱
- 最终需要人工重置

---

### 4. 模型可能无法判断优先级，反复摇摆

如果冲突信息没有标注优先级，模型可能在不同轮次选择不同版本。

例如：

- 第一轮按 React 处理
- 第二轮又按 Vue 处理
- 第三轮混合两者

**后果：**

- 输出不稳定
- 无法收敛
- 用户无法信任结果

---

### 5. 冲突会掩盖真正的问题

有时冲突信息本身不是核心问题，但它会消耗模型注意力。

例如：

```text
文件 A 说配置在 config.json
文件 B 说配置在 config.yaml
```

模型可能花大量时间判断哪个文件存在，而不是解决原始任务。

**后果：**

- 注意力被冲突吸引
- 真正关键信息被忽略
- 任务效率下降

---

### 6. 最危险：模型没有意识到冲突

如果冲突信息被平铺在长 Context 中，模型可能：

- 完全没注意到两者矛盾
- 同时引用两者
- 产生看似合理但逻辑错误的输出

**后果：**

- 错误难以发现
- 用户误以为模型已综合所有信息
- 调试成本极高

---

## 冲突信息的常见来源

| 来源 | 例子 |
|---|---|
| 新旧信息混合 | 旧文档 vs 最新代码 |
| 多来源信息 | 用户描述 vs 代码实际 |
| 工具结果不一致 | 两个工具返回不同结果 |
| 历史决策变更 | 之前选 A，现在改选 B |
| 压缩导致丢失优先级 | 摘要后只剩并列信息 |

---

## 如何处理冲突信息

核心原则：

> **不要指望模型自己裁决冲突，要显式告诉它结论和优先级。**

推荐做法：

1. **标注冲突**

```text
冲突：
- 旧文档：React（已废弃）
- 用户最新确认：Vue（以此为准）
```

2. **标注时效**

```text
[最新] Vue
[过期] React
```

3. **标注权威来源**

```text
以最新代码为准，文档仅供参考。
```

4. **压缩时保留优先级**
	 不能只留并列信息，必须保留"谁优先"。

5. **必要时移除过期版本**
	 如果确认无用，直接删除，避免干扰。

---

## 总结

Context 中出现冲突信息会导致：

| 问题 | 表现 |
|---|---|
| 随机选择 | 选错版本或混合两者 |
| 采用过期信息 | 基于废弃方案推理 |
| 错误累积 | 多轮循环越走越偏 |
| 反复摇摆 | 不同轮次结论不一致 |
| 掩盖真问题 | 注意力被冲突消耗 |
| 隐性错误 | 模型未意识到冲突 |

一句话：

> Context 中的冲突信息，不会让模型停下来，而会让它在一个自相矛盾的世界模型上继续推理。

因此 Context Engineering 的重要任务之一是：

> **显式标注冲突、时效和优先级，而不是把矛盾信息平铺给 LLM。**
