## 问题

Context 缺少关键信息会发生什么？

## 回答

Context 缺少关键信息时，LLM 不会停下来，而是会**在错误或不完整的世界模型上继续推理**。

主要后果：

1. **脑补缺失信息**
	 根据常见模式猜测，产生幻觉文件、API、依赖或方案。

2. **给出通用但无用的回答**
	 回答看似正确，但无法执行，无法解决具体问题。

3. **错误累积**
	 Agent 多轮循环中，第一轮的错误假设会导致后续 Tool Call 全部跑偏。

4. **违反项目约束**
	 不知道限制条件，可能给出项目不允许的方案。

5. **使用过期或冲突信息**
	 重复已失败的方案，或无法判断哪个信息是权威来源。

6. **Agent 循环失败**
	 Context 更新不完整，导致重复调用、无法收敛、成本飙升。

7. **最危险：模型不知道自己缺信息**
	 自信地给出错误答案，用户误以为问题已解决。

一句话：

> Context 缺少关键信息，不会让 LLM 停下来，而会让它在一个错误的世界模型上继续推理。
