> [!tip] 一个岗位一篇笔记，列 = `apply_status`
> 卡片在 `10-PROJECTS/P-Agent求职/投递记录/`。拖到「面试中」时把 `interview_round` 填上（一面/二面/HR），下一轮不用再挪列，只改数字。
> 被拒或自己放弃也拖过去，**历史留痕比看板干净更重要**——投递量、转化率、卡在哪个环节，只有记录全了才算得出来。

![[求职投递.base]]

## 属性说明

| 属性 | 取值 | 用途 |
|:---|:---|:---|
| `apply_status` | 投递 / 笔试 / 面试中 / Offer / 已拒 | 看板分列依据 |
| `company` | 公司名 | 卡片副标题 |
| `position` | 岗位全称 | 总表 |
| `channel` | BOSS / 官网 / 内推 / 猎头 | 判断哪条渠道有效 |
| `applied_date` | 投递日期 | 总表默认按此倒序 |
| `interview_round` | 一面 / 二面 / HR | 仅 `面试中` 时填写 |
| `next_action` | 待办一句话 | 卡片上直接可见 |
| `salary` / `city` | 可选 | 便于横向比较 |

## 建卡方式

1. 看板任一列的列头有 `+`，点它新建，`apply_status` 会自动填成该列的值
2. 或手动在 `投递记录/` 新建笔记，文件名用 `公司-岗位`，复制上面的属性

> 首次使用：看板当前为空，第一张卡建立后列才会出现内容。列本身已由 `groupOrder` 固定，不会因为有值为空而消失。
