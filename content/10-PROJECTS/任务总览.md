> [!info] 这里为什么没有四象限
> 全库 `- [ ]` 共 655 项，但不是同一种东西：
> - `10-PROJECTS` 71 项、`20-AREAS` 63 项 → **推进清单**，值得被看见
> - `30-RESOURCES` 406 项 → 题单、学习大纲的勾选（`Agent学习清单`、`每日一题题单` 之类），**不是待办**
> - `90-DIARY` 82 项 → 日记里的当日清单，随日期失效
>
> 而 71 + 63 项里，**带日期 0 个、带优先级 0 个**。四象限需要「重要」和「紧急」两个维度，现在一个维度的数据都没有。硬套只能靠给上百个勾选项补字段——那个成本不会有人付。
>
> 结论：这里只做**分组可见**，不做优先级排序。要真用四象限，得先给任务加 `#Q2` 之类的标签，那是下一个决定，不是这个视图能解决的。

## 项目推进（10-PROJECTS）

```tasks
not done
path includes 10-PROJECTS
group by filename
hide backlink
```

## 领域待办（20-AREAS）

```tasks
not done
path includes 20-AREAS
group by filename
hide backlink
```

## 最近完成（10-PROJECTS）

```tasks
done
path includes 10-PROJECTS
limit 10
hide backlink
```

> 这些任务都没有日期，所以「逾期」「今日到期」这类查询在这里永远为空——不是视图坏了，是数据里没这个信息。
