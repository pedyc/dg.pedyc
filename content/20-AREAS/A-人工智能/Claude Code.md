## Area: Claude Code

> Claude Code 是一个由 AI 驱动的代理编码工具，可以读取代码库、编辑文件、运行命令，并与开发工具集成。

---

### 领域定义

- **核心范畴**：终端/IDE/桌面应用中的 AI 编程助手，自动化开发任务
- **不包括**：非编程任务、图形设计、文案撰写
- **与相关领域的区别**：
	- VS Copilot：侧重交互式编程，深度代码库理解
	- VS ChatGPT：深度集成开发环境，原生 CLI
