## ⚙️ 工具：Claude Code

> [!abstract]
> Claude Code 是一个代理编码工具，可以读取你的代码库、编辑文件、运行命令，并与你的开发工具集成。可在终端、IDE、桌面应用和浏览器中使用。
>
> Claude Code 是一个由 AI 驱动的编码助手，可以帮助你构建功能、修复错误和自动化开发任务。它理解你的整个代码库，可以跨多个文件和工具工作以完成任务。
