## Area: JavaScript

> 浏览器与 Node.js 共同的脚本语言：核心概念、运行机制、异步模型与版本演进。

### 领域定义

- **核心范畴**：语言核心（作用域、原型、this）、运行机制（事件循环、执行上下文、引擎）、异步编程、版本与模块
- **不包括**：框架用法（属 [[Vue]] / [[React]] / [[Angular]]）、浏览器宿主行为（属 [[浏览器]]）
- **与相关领域的区别**：本领域答「语言本身怎么运作」，[[浏览器]] 答「它跑在什么环境里」；[[TypeScript]] 是本领域的类型化超集，边界在「类型系统」一侧
