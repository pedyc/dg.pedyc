```dataview
TABLE WITHOUT ID file.link AS "领域", length(file.inlinks) AS "被引用", file.mtime AS "最近更新"
FROM "20-AREAS"
WHERE content-type = "area"
SORT length(file.inlinks) DESC
```

> 原表有一列 `file.status AS "状态"`。`status` 已是废除字段（见 [[元数据规范]]），且 Dataview 读 frontmatter 用的是字段名本身、不是 `file.status`，所以那一列从来就是空的。现在换成「被引用」与「最近更新」——两者都是文件系统给的事实，不会与正文里的健康度打架。
