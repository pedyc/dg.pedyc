## 术语：ES2015

> **别名**: ECMAScript 2015, ES6
> **领域**: #前端开发/JavaScript/标准

### 定义

ES2015 (ECMAScript 2015) 是 ECMAScript 标准的第六个版本，也常被称为 ES6。它是 JavaScript 最重要的更新之一，引入了大量新语法，极大提升了 JavaScript 的开发体验。

### 新特性

| 特性 | 说明 |
|------|------|
| `let` / `const` | 块级作用域声明 |
| 箭头函数 | 简化的函数语法，`this` 词法绑定 |
| 模板字符串 | 支持嵌入变量的字符串 |
| 解构赋值 | 从数组/对象中提取值 |
| `class` | 类语法糖 |
| 模块 import/export | 原生模块系统 |
| `Promise` | 异步编程 |
| `async/await` | 异步语法糖 |
| `Map` / `Set` | 新数据结构 |
| 箭头函数 | 简化的函数语法 |
