## 术语：ES2025

> **别名**: ECMAScript 2025
> **领域**: #前端开发/JavaScript/标准

### 定义

ES2025（ECMAScript 2025）是 ECMA-262 第 16 版，2025 年 6 月批准，共 11 项特性。重点是把迭代器、Set、正则三处的常用手写逻辑收进标准库，没有语法层重构。

### 新特性

| 特性 | 说明 |
|------|------|
| **Iterator Helpers** | 迭代器辅助方法：`map`/`filter`/`take`/`drop`/`flatMap`/`reduce`/`toArray`，惰性求值 |
| **Set 方法** | `union`、`intersection`、`difference`、`symmetricDifference`、`isSubsetOf`、`isSupersetOf`、`isDisjointFrom` |
| **Import Attributes** | `import … with { type: "json" }`，取代非标准的 `assert` |
| **JSON 模块** | 原生 JSON 导入，无需打包器插件 |
| **Promise.try()** | 把同步抛错与异步拒绝收进同一条 catch 链 |
| **Float16Array** | 半精度浮点数组，配合 `Math.f16round()` |
| **RegExp.escape()** | 安全转义字符串中的正则特殊字符 |
| **RegExp 修饰符** | `(?i:…)` / `(?-i:…)` 局部开关标志位 |
| **Duplicate Named Capture Groups** | 同名捕获组可出现在不同分支 |
| **RegExp /v 标志** | `/u` 的升级版，支持集合表示法与字符串字面量 |

### 常被误算进本版的三项

原文把下面三项列成了 ES2025 特性，都不是：`Pattern Matching` 仍是提案、未进任何年度版本；`Records & Tuples` 2025-04 被 TC39 撤回，由 Composites 接替；`Error Cause` 是 ES2022、`Atomics.waitAsync` 是 ES2024。示例代码保留在这里，注意模式匹配的语法尚未定案。

#### Pattern Matching（提案，语法未定）

```javascript
// 模式匹配
const result = match (data) {
  { status: 200, body } => handleSuccess(body),
  { status: 404 } => handleNotFound(),
  { status: code } if code >= 500 => handleServerError(code),
  _ => handleUnknown()
};
```

#### Records & Tuples（已撤回）

```javascript
// 不可变数据结构
const point = #{ x: 1, y: 2 };  // Record (对象)
const coords = #[1, 2, 3];       // Tuple (数组)

// 不可变性
const updated = point.#{ x: 3 }; // 浅拷贝并修改
```
