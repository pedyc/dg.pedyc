## 术语：L系统（L-system / Lindenmayer System）

> **主题**：#计算机图形学/程序化生成

### 定义

**L系统（Lindenmayer 系统）** 是一种并行重写系统（parallel rewriting system），即一种形式语法，由匈牙利生物学家 Aristid Lindenmayer 于 1968 年提出。它通过递归应用产生规则（production rules），从初始状态（axiom）出发生成字符序列，再将这些字符解释为几何指令，从而产生自相似的分形结构——最经典的应用是模拟植物生长形态。

**形式定义**：L系统是一个三元组 G = (V, ω, P)，其中：

- **V**（字母表）：包含可被替换的符号（变量）和不可替换的符号（常量/终结符）
- **ω**（初始状态/公理）：由 V 中符号组成的初始字符串
- **P**（产生规则集）：定义变量如何被替换为变量和常量的组合

**与 Chomsky 语法的关键区别**：L系统的规则应用是**并行的**——每一步中所有可替换的符号同时被替换（而非顺序替换）。这使得它天然适合描述生物体的细胞分裂和分枝生长。

### 示例：巴恩斯利蕨（Barnsley Fern）

```plaintext
变量: X, F
常量: +, -, [, ]
初始: -X

规则:
(X → F+[[X]-X]-F[-FX]+X)
(F → FF)
```

**几何解释**（龟图 turtle graphics）：
- `F` — 向前画线
- `-` — 右转 25°
- `+` — 左转 25°
- `X` — 空操作（仅用于结构生成）
- `[` — 将当前位置和角度压入栈
- `]` — 从栈中弹出位置和角度（回到分叉点）

### 概率 L 系统（Probabilistic L-System）

在实际应用中（如[[斑驳光]]的树枝生成），常用**概率语法**产生更自然的随机分枝：

```plaintext
变量: X, F
常量: +, -, [, ]
初始: X

规则（概率分布）:
(X → FX)            p = 0.300   主干延伸，不分叉
(X → F[+X]X)        p = 0.245   分叉：主干 + 一个右侧枝
(X → F[-X]X)        p = 0.245   分叉：主干 + 一个左侧枝
(X → F[+X][-X]X)    p = 0.210   分叉：主干 + 双侧枝
```

与标准 L 系统不同，概率 L 系统持续展开直到所有分枝达到终止宽度，输出的是分枝/树干的线段列表，可传给片段着色器按距离场渲染。

### 跨学科含义

- **在植物学中**：L系统用于建模植物拓扑结构（分枝模式、叶序排列），揭示生长规则与最终形态的关系。配合达·芬奇分枝法则（截面积守恒）和黄金角叶序（137.5°），可产生高度逼真的虚拟植物。
- **在计算机图形学中**：L系统是程序化内容生成（PCG）的基础工具，用于生成树木、城市道路网、河流系统等地形特征。
- **在形式语言理论中**：L系统是 Chomsky 层级之外的并行语法体系，属于"开发语言"（developmental languages）家族。
