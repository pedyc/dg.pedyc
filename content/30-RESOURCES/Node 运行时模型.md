## MOC：Node 运行时模型

> 本 MOC 只索引「代码何时拿到控制权」这一段：事件循环怎么分阶段、libuv 的线程池在什么时候被调用、什么写法会把这条线程占住。下界到「哪段代码先跑」，上界到「为什么这里会卡」。
> 模块加载与数据流不在此列，各有自己的 MOC——本页只到调度为止。

### 核心原则

分类依据只有一条：这段是**调度**还是**代价**。调度讲谁先谁后，代价讲什么写法会让先后失效。纯 API 参数与用法不进本页。

### 调度：谁在什么时候拿到控制权

- [[事件循环]] — 通用模型，以浏览器视角为主，Node 的六阶段差异只占一行
- [[JS执行机制]] — 引擎执行与宿主调度的交接点，本 MOC 只接宿主那一半
- [[宏任务]] — 任务粒度较大的一侧，每轮取一个
- [[微任务]] — 每个宏任务结束后整队清空

### 引擎与运行时底座

- [[JavaScript 引擎]] — 编译与执行的分层
- [[V8 引擎]] — Node 与 Chrome 共用的那个实现
