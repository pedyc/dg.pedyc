> Vapor Mode 是什么？

---

## 背景

Vapor Mode 是 Vue 团队正在探索的新编译策略，旨在进一步提升性能。

---

## 现有答案

### 答案 1：概念

Vapor Mode 是一种新的编译输出模式，直接生成高效的 JavaScript 代码，绕过虚拟 DOM。

### 答案 2：优势

- 消除虚拟 DOM 运行时代价
- 更接近原生 JavaScript 性能
- 保留 Vue 的响应式和组件化

### 答案 3：现状

目前处于实验阶段，与现有模式共存。
