## MOC: Web安全问题

> 常见的 Web 安全攻击类型及其防御策略索引

---

### 攻击类型分类

#### 渲染层攻击

- **[[XSS]]** — 跨站脚本攻击，注入恶意脚本
- **[[CSRF]]** — 跨站请求伪造，诱导用户执行非预期操作

#### 传输层攻击

- **SSL Stripping** — SSL 剥离攻击，将 HTTPS 降级为 HTTP
- **中间人攻击 (MITM)** — 拦截通信链路

#### 认证与会话

- **会话劫持** — 盗取用户会话 ID
- **密码猜测** — 暴力破解认证凭证

---

### 防御原则

1. **输入过滤**：所有用户输入都不可信，需验证和消毒
2. **输出编码**：渲染时对特殊字符进行 HTML 编码
3. **CSRF Token**：关键操作要求携带随机 Token
4. **强制 HTTPS**：使用 HSTS 防止降级攻击
5. **内容安全策略**：CSP 限制资源加载来源
