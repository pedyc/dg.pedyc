> [!tip] 一本书一篇笔记，列 = `read_status`
> 卡片在 `30-RESOURCES/书单/`，PDF 原文在 `99-ASSETS/书籍/`（不入 git，见 `.gitignore`）。
> 把卡片拖到「在读」即改写 `read_status`；读完补 `rating`。

![[书单.base]]

## 属性说明

| 属性 | 取值 | 用途 |
|:---|:---|:---|
| `read_status` | 想读 / 在读 / 已读 / 弃读 | 看板分列依据 |
| `book_genre` | AI Agent / 提示词工程 / 知识管理 / … | 卡片副标题、总表分组 |
| `book_format` | PDF / 纸质 / 电子书 | 载体 |
| `rating` | 空白，待填 | 读后打分（1–10） |
| `pdf` | `[[xxx.pdf]]` | 指向 `99-ASSETS/书籍/` 的原文 |

## 新增一本书的做法

1. 在 `30-RESOURCES/书单/` 新建笔记，文件名 = 书名
2. 复制上述 frontmatter，`read_status` 填 `想读`
3. 把 PDF 放进 `99-ASSETS/书籍/`，用 `pdf: "[[文件名.pdf]]"` 指过去
4. 看板会自动多一张卡，无需改 `.base`
