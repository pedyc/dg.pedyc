LeetCode 198题：[打家劫舍](https://leetcode.cn/problems/house-robber)

## 一、先看递归版本

```javascript
function dfs(i) {
    if (i < 0) return 0;
    if (i === 0) return nums[0];

    const notRob = dfs(i - 1);
    const rob = nums[i] + dfs(i - 2);

    return Math.max(notRob, rob);
}
```

关键观察：

> `dfs(i)` 只依赖 `dfs(i - 1)` 和 `dfs(i - 2)`。

这意味着，如果我们**按 `i` 从小到大计算**，就能保证计算 `dfs(i)` 时，它需要的两个值已经算好了。

这就是从递归到递推的**核心洞察**。

---

## 二、第一步：加记忆化

纯递归的问题是重复计算。加 `memo`：

```javascript
const memo = new Array(n).fill(-1);

function dfs(i) {
    if (i < 0) return 0;
    if (i === 0) return nums[0];
    if (memo[i] !== -1) return memo[i];

    memo[i] = Math.max(dfs(i - 1), nums[i] + dfs(i - 2));
    return memo[i];
}
```

现在 `memo[i]` 保存了 `dfs(i)` 的结果，每个状态只算一次。

**但递归还是"自顶向下"的**：从 `dfs(n-1)` 开始，一路递归到 `dfs(0)`，再一层层返回。

---

## 三、第二步：把 `memo` 看成一张表

`memo[i]` 就是 `dfs(i)` 的答案。我们可以给它换个名字：`dp[i]`。

```text
dp[i] = 考虑 [0, i] 的房子，能偷到的最大金额
```

递归的转移：

```text
dfs(i) = max(dfs(i-1), nums[i] + dfs(i-2))
```

换成 `dp`：

```text
dp[i] = max(dp[i-1], nums[i] + dp[i-2])
```

**这就是递推公式。**

---

## 四、第三步：确定计算顺序

递归是自顶向下的：

```text
dfs(n-1)
  -> dfs(n-2)
    -> dfs(n-3)
      -> …
        -> dfs(0)
```

而递推是自底向上的：

```text
dp[0]
  -> dp[1]
    -> dp[2]
      -> …
        -> dp[n-1]
```

为什么可以这样？因为：

> `dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，这两个都比 `i` 小。

所以只要**从小到大**计算，计算 `dp[i]` 时，它需要的值已经准备好了。

---

## 五、第四步：确定边界

递归的边界：

```text
dfs(-1) = 0
dfs(0)  = nums[0]
```

对应到 `dp`：

```text
dp[0] = nums[0]
```

`dp[-1]` 不存在，但 `dp[1]` 需要它：

```text
dp[1] = max(dp[0], nums[1] + dp[-1])
      = max(nums[0], nums[1] + 0)
      = max(nums[0], nums[1])
```

所以 `dp[1]` 要单独处理。

---

## 六、第五步：写出递推代码

```javascript
var rob = function (nums) {
    const n = nums.length;
    if (n === 0) return 0;
    if (n === 1) return nums[0];

    const dp = new Array(n);
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);

    for (let i = 2; i < n; i++) {
        dp[i] = Math.max(dp[i - 1], nums[i] + dp[i - 2]);
    }

    return dp[n - 1];
};
```

对照递归：

| 递归 | 递推 |
|---|---|
| `dfs(i)` | `dp[i]` |
| `dfs(i-1)` | `dp[i-1]` |
| `dfs(i-2)` | `dp[i-2]` |
| `dfs(-1) = 0` | `dp[-1] = 0`（隐含） |
| `dfs(0) = nums[0]` | `dp[0] = nums[0]` |
| 从 `dfs(n-1)` 开始 | 从 `dp[0]` 开始 |
| 自顶向下 | 自底向上 |

## 七、递归和递推的对应关系

```text
递归版本：
    dfs(n-1)
      -> dfs(n-2)
        -> dfs(n-3)
          -> …
            -> dfs(0)
              -> dfs(-1)

递推版本：
    dp[0]
      -> dp[1]
        -> dp[2]
          -> …
            -> dp[n-1]
```

**递归是"从终点往回找"，递推是"从起点往前推"。**

两者算的是同一张表，只是计算顺序相反。

---

## 八、为什么可以转换

核心条件有两个：

### 1. 无后效性

> `dp[i]` 只依赖比 `i` 小的状态，不依赖比 `i` 大的状态。

所以从小到大计算是安全的。

### 2. 重叠子问题

> `dfs(i)` 会被多次调用。

所以需要 `memo` / `dp` 来避免重复计算。

满足这两点，递归就可以转成递推。

---

## 九、递归 → 递推的通用步骤

```text
1. 写出递归函数 dfs(i)，明确它的含义。
2. 写出转移方程：dfs(i) = … dfs(i-1) … dfs(i-2) …
3. 确定边界：dfs(0)、dfs(-1) 等。
4. 把 dfs 换成 dp：dp[i] = … dp[i-1] … dp[i-2] …
5. 确定计算顺序：从小到大（因为 dp[i] 依赖更小的 i）。
6. 处理边界：dp[0]、dp[1] 单独赋值。
7. 写出 for 循环。
8. 返回 dp[n-1]（或题目要求的值）。
```

---

## 十、再优化：滚动变量

观察递推公式：

```text
dp[i] = max(dp[i-1], nums[i] + dp[i-2])
```

`dp[i]` 只依赖前两个值，所以不需要整个数组，只需要两个变量：

```javascript
var rob = function (nums) {
    const n = nums.length;
    if (n === 0) return 0;
    if (n === 1) return nums[0];

    let prev2 = nums[0];                      // dp[i-2]
    let prev1 = Math.max(nums[0], nums[1]);   // dp[i-1]

    for (let i = 2; i < n; i++) {
        const cur = Math.max(prev1, nums[i] + prev2);
        prev2 = prev1;
        prev1 = cur;
    }

    return prev1;
};
```

空间从 `O(n)` 降到 `O(1)`。

---

## 十一、三种版本的对比

| 版本 | 时间复杂度 | 空间复杂度 | 计算方向 |
|---|---|---|---|
| 纯递归 | `O(2^n)` | `O(n)` | 自顶向下 |
| 记忆化递归 | `O(n)` | `O(n)` | 自顶向下 |
| 递推（数组） | `O(n)` | `O(n)` | 自底向上 |
| 递推（滚动变量） | `O(n)` | `O(1)` | 自底向上 |

---

## 十二、一句话总结

> **递归是"从大问题往回找"，递推是"从小问题往前推"。**
> **能转换的前提是：状态只依赖更小的状态（无后效性）+ 有重叠子问题。**
> **转换方法：把 `dfs(i)` 换成 `dp[i]`，把递归调用换成数组下标，把边界写成初始值，把递归方向反过来写成 `for` 循环。**
