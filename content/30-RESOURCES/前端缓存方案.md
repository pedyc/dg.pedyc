### 浏览器缓存

- [[BOM]] — 浏览器对象模型，localStorage/sessionStorage 所在
- [[Cache API]] — Service Worker 缓存资源的 API
- [[HTTP缓存机制]] — 存储期与复用期五条件；强缓存与协商缓存是同一次查找的两个分支

### 客户端存储

- [[IndexedDB]] — 客户端持久化存储，缓存 API 响应、离线数据存储
- [[localStorage 的「长期」只是不会被主动过期]] — ~5 MB，同步阻塞主线程
- [[sessionStorage 的「会话」指标签页，不是登录状态]] — 标签页关闭即失效

### 运行时缓存

- 内存缓存 — 运行时变量与计算结果，存在 JS 堆里，随页面销毁（无独立笔记，见[[前端缓存怎么分类]]的「运行时缓存」一行）
- [[V8 引擎]] — JIT 编译优化、隐藏类
- [[Web Worker]] — Worker 线程独立上下文
