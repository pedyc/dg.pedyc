## 核心思想

> 回溯算法本质上是在一棵**决策树**上做 DFS（**DFS+ 状态撤销**。）
> 把求解过程想象成在一棵"决策树"上走路径。
> 状态撤销：**进入某条分支前修改状态，离开时恢复原状**

## 回溯算法的核心步骤

```js
path.push(c);      // 做选择
dfs(i + 1);        // 递归
path.pop();        // 撤销选择  ← 关键一步
```

### 思考模板

1. 原问题 —— 整体要解决什么
2. 子问题 —— dfs 的语义
3. 决策树 —— 有哪些选择，通向哪些状态
4. 当前操作 —— 做选择 / 判断答案
5. 状态转移 —— 下一个子问题是谁
6. 边界条件 —— 什么时候收集、什么时候返回
7. 回溯 —— 撤销选择，恢复现场

```js
// 回溯 + 剪枝
// 原问题：将字符串 s 分割成所有合法的 IP 地址。
// 子问题：dfs(start, segCount)
//         已经从 s[0..start-1] 分出了 segCount 段合法 IP 段，
//         现在要从 start 开始，继续分割剩下的部分。
// 决策树：
//         当前状态 (start, segCount)
//         ├── 切 1 位：s[start:start+1]
//         ├── 切 2 位：s[start:start+2]
//         └── 切 3 位：s[start:start+3]
//         每个分支判断该段是否合法。
// 当前操作：
//         枚举当前段结束下标 i，范围 [start, min(start+2, n-1)]；
//         sub = s[start:i+1]；
//         判断 sub 是否合法（无前导 0、数值 ≤ 255）；
//         若合法，path.append(sub)。
// 下一个子问题：
//         dfs(i + 1, segCount + 1)
// 边界条件：
//         start == n 且 segCount == 4 -> 收集答案；
//         segCount == 4 且 start < n -> 剪枝；
//         剩余长度不在 [剩余段数, 剩余段数 * 3] -> 剪枝。
// 回溯：
//         path.pop()
def dfs(start):
    if start == len(s):              # 6. 边界
        res.append(path[:])
        return

    for i in range(start, len(s)):   # 3. 决策树
        sub = s[start:i+1]
        if sub != sub[::-1]:         # 剪枝
            continue
        path.append(sub)             # 4. 当前操作
        dfs(i + 1)                   # 5. 状态转移
        path.pop()                   # 7. 回溯

dfs(0)                               # 2. 子问题入口
```

## 示例

以 [LeetCode-17 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/) 为例

### 这棵树长什么样？

```bash
                    root (i=0, 处理数字 '2')
        ┌──────────┼──────────┐
        a                      b                     c        <- 第 1 层：选 '2' 对应的某个字母
      / | \                  / | \                 / | \
     d  e  f                d  e  f               d  e  f     <- 第 2 层：选 '3' 对应的某个字母
```

- 树的**深度** = 数字个数 `n`。
- 第 `i` 层的**分支数** = `digits[i]` 对应字母的个数。
- 从根到叶的一条完整路径，就是一个答案（如 `a→d` 得 `"ad"`）。
