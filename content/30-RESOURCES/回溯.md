## 核心思想

> 回溯算法本质上是在一棵**决策树**上做 DFS（**DFS+ 状态撤销**。）
> 把求解过程想象成在一棵"决策树"上走路径。
> 状态撤销：**进入某条分支前修改状态，离开时恢复原状**

## 回溯算法的核心步骤

```js
path.push(c);      // 做选择
dfs(i + 1);        // 递归
path.pop();        // 撤销选择  ← 关键一步
```

### 思考模板

1. 原问题
	 把整个字符串 s 分割成若干回文子串。
2. 子问题
	 dfs(start)：从 start 开始，把 s[start..] 切完。
3. 决策树
	 start=0
		├── 切 "a" -> start=1
		├── 切 "aa" -> start=2
		└── 切 "aab" -> 不是回文，剪枝
4. 当前操作
	 枚举 i，判断 s[start:i+1] 是否回文；
	 是则 path.append(s[start:i+1])。
5. 状态转移（下一个子问题）
	 dfs(i + 1)
6. 边界条件
	 start == len(s) 时，收集 path[:]，返回。
7. 回溯
	 path.pop()

```python
def dfs(start):
    if start == len(s):          # 6. 边界
        res.append(path[:])
        return

    for i in range(start, len(s)):   # 3. 决策树
        sub = s[start:i+1]
        if sub != sub[::-1]:         # 剪枝
            continue
        path.append(sub)             # 4. 当前操作
        dfs(i + 1)                   # 5. 状态转移
        path.pop()                   # 7. 回溯

dfs(0)                               # 2. 子问题入口
```

## 示例

以 [LeetCode-17 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/description/) 为例

### 这棵树长什么样？

```bash
                    root (i=0, 处理数字 '2')
        ┌──────────┼──────────┐
        a                      b                     c        <- 第 1 层：选 '2' 对应的某个字母
      / | \                  / | \                 / | \
     d  e  f                d  e  f               d  e  f     <- 第 2 层：选 '3' 对应的某个字母
```

- 树的**深度** = 数字个数 `n`。
- 第 `i` 层的**分支数** = `digits[i]` 对应字母的个数。
- 从根到叶的一条完整路径，就是一个答案（如 `a→d` 得 `"ad"`）。
