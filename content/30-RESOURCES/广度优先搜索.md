## 概念：广度优先搜索

> 广度优先搜索（BFS）是一种图的遍历算法，从起始节点出发，先访问所有相邻节点，再逐层向外扩展，直到找到目标或遍历完成。

> 从树的视角看：从根节点开始，沿着树的宽度遍历节点，若所有节点均被访问则算法中止。BFS 通常用队列实现，先进先出的结构确保先被访问的节点其邻居也先被访问。

**解决的问题**：寻找最短路径、层级遍历、最短距离

```bash
         A         
       /   \
      B     C   
     / \   / \
    D   E F   G     
```

访问顺序: A → B → C → D → E → F → G

### 具体实现

#### 1. 队列实现（标准）

```javascript
function bfs(root) {
    if (root === null) return;
    const queue = [root];        // 用数组模拟队列
    while (queue.length > 0) {
        const node = queue.shift(); // 从队头取出（FIFO）
        console.log(node.val);      // 访问当前节点
        if (node.left)  queue.push(node.left);   // 左子入队
        if (node.right) queue.push(node.right);  // 右子入队
    }
}
```

#### 2. 层序遍历

```javascript
function bfsByLevel(root) {
    if (root === null) return [];

    const result = [];
    const queue = [root];

    while (queue.length > 0) {
        const levelSize = queue.length; // 当前层的节点数
        const level = [];

        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift();
            level.push(node.val);

            if (node.left)  queue.push(node.left);
            if (node.right) queue.push(node.right);
        }

        result.push(level); // 把这一层存起来
    }

    return result;
}
```

#### 3. 最短路径

```javascript
function shortestPath(graph, start, target) {
  if (start === target) return 0;

  const visited = new Set();
  const queue = [[start, 0]];
  visited.add(start);

  while (queue.length > 0) {
    const [node, dist] = queue.shift();

    for (const neighbor of graph[node]) {
      if (neighbor === target) return dist + 1;

      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push([neighbor, dist + 1]);
      }
    }
  }

  return -1; // 无法到达
}
```

### 与深度优先搜索对比

| 维度     | BFS         | DFS        |
| :----- | :---------- | :--------- |
| 数据结构   | 队列          | 栈/递归       |
| 搜索顺序   | 一层一层横扫      | 一条路走到底，再回溯 |
| 空间复杂度  | O(W)，W=最大层宽 | O(H)，H=树高  |
| 找到最短路径 | 是           | 否          |
| 适用场景   | 最短路径、层级遍历   | 深层搜索、路径检测  |
