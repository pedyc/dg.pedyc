## 术语：建造者模式

> **主题**：#软件工程/设计模式

### 定义

**建造者模式**（Builder Pattern）是一种创建型设计模式，将复杂对象的构建过程分解为多个步骤，通过指导者（Director）控制构建顺序，最终返回完整对象。与工厂模式的区别在于：工厂模式一步创建对象，建造者模式分步构建。

```typescript
class PizzaBuilder {
  private dough: string = '';
  private sauce: string = '';
  private toppings: string[] = [];

  setDough(dough: string): this {
    this.dough = dough;
    return this;
  }
  setSauce(sauce: string): this {
    this.sauce = sauce;
    return this;
  }
  addTopping(topping: string): this {
    this.toppings.push(topping);
    return this;
  }
  build(): Pizza {
    return new Pizza(this.dough, this.sauce, this.toppings);
  }
}

// Fluent interface
const pizza = new PizzaBuilder()
  .setDough('thin')
  .setSauce('tomato')
  .addTopping('cheese')
  .build();
```

### 跨学科含义

- **在 Java 中**：`StringBuilder`、`StringBuffer` 是建造者模式的经典实现。Lombok 的 `@Builder` 注解自动生成建造者代码。
- **在前端开发中**：配置对象构建（如 Axios 实例配置、Chart.js 图表选项）常采用建造者风格的链式调用。Redux Toolkit 的 `createSlice` 内部也使用了类似构建流程。
