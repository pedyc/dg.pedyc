## 术语：概率云

> **领域**：#物理学/量子力学

### 定义

概率云（Probability Cloud）是量子力学中用**波函数**描述微观粒子位置概率分布的模型。粒子在观测前没有确定位置，而是以概率形式弥漫在空间中。

**核心公式**：

```bash
|Ψ(x,y,z)|² = 在某点发现粒子的概率密度
```

- Ψ：波函数（复数）
- |Ψ|²：概率密度（实数）

**薛定谔方程**（描述波函数演化）：

```bash
iℏ ∂Ψ/∂t = ĤΨ
```

---

### 核心特点

| 特点 | 说明 |
|:---|:---|
| **概率性** | 粒子位置只能计算概率，无法精确预测 |
| **波粒二象性** | 微观粒子同时具有波动性和粒子性 |
| **观测坍缩** | 观测后波函数坍缩为确定状态 |
| **不确定性** | 位置和动量不能同时精确确定（海森堡原理） |
| **非经典轨道** | 不存在经典物理中的确定轨道 |

---

### 跨学科含义

- **在量子力学中**：概率云是哥本哈根诠释的核心概念，粒子以概率形式存在
- **在化学中**：电子轨道本质是概率分布，s/p/d 轨道是概率云的数学描述
- **在哲学中**：引发 " 决定论 vs 随机论 " 的争论
