## 概念：深度优先搜索

> 深度优先搜索（DFS）是一种树/图的遍历算法，从起始节点出发，沿着一条路径不断深入直到无法继续，然后回溯搜索其他路径。

**解决的问题**：遍历树/图结构、寻找路径、检测环路

```bash
        A
       / \
      B   C
     / \
    D   E
    
```

DFS 的物理走法都是：`A → B → D → (回B) → E → (回B) → (回A) → C`

### 具体实现

- 前序遍历，先处理根再遍历：A B D E C
- 中序输出，先处理左再遍历：D B E A C
- 后序输出，先处理右再遍历：D E B C A

#### 1. 前序

```javascript
function dfs(root) {
    if (root === null) return;
    console.log(root.val);   // 先处理自己
    preorder(root.left);     // 再左
    preorder(root.right);    // 再右
}
```

#### 2. 中序

```js
function inorder(root) {
    if (root === null) return;
    inorder(root.left);      // 先左
    console.log(root.val);   // 再处理自己
    inorder(root.right);     // 再右
}
```

#### 3. 后序

```js
function postorder(root) {
    if (root === null) return;
    postorder(root.left);    // 先左
    postorder(root.right);   // 再右
    console.log(root.val);   // 最后处理自己
}
```

---

### 与广度优先搜索对比

| 维度 | DFS | BFS |
|:---|:---|:---|
| 数据结构 | 栈 | 队列 |
| 搜索顺序 | 深度优先 | 层级优先 |
| 空间复杂度 | O(H)，H=树高 | O(W)，W=最大层宽 |
| 找到最短路径 | 否 | 是 |
| 适用场景 | 深层搜索、路径检测 | 最短路径、层级遍历 |
