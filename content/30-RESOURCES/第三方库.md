## MOC：前端第三方库地图

收录现代前端（SPA / 全栈 / Node.js 工具链）在架构开发中高频使用的基准工业级三方库，以及具有突出特色、轻量化创新或前沿体验的细分开源工具，作为团队选型决策、依赖替代与技术储备的导航中枢。

---

### 类型约束与数据校验

* [[Zod]] — 基于 TypeScript 优先的声明式运行时 Schema 声明与类型推导库
* [[Valibot]] — 极其小巧、模块化优先的类型校验库，体积仅为 Zod 的十分之一左右
* [[ArkType]] — 以极快运行时性能与纯 TS 字符串类型内联定义为特色的新一代验证工具
* [[TypeBox]] — 基于 JSON Schema 规范构建、深度适配 OpenAPI 与高性能 RPC 契约的校验器

### 数据请求与服务端状态

* [[TanStack Query]] — 异步数据请求、缓存管理、失效控制与自动流式同步框架（前身 React Query）
* [[SWR]] — Next.js 团队推出的轻量级陈旧重验（Stale-While-Revalidate）数据请求 Hooks
* [[tRPC]] — 端到端类型安全的无 Schema RPC 通信协议，消除前后端接口胶水代码
* [[Ky]] — 基于现代浏览器原生 Fetch API 封装的优雅轻量 HTTP 客户端（Axios 的轻量替代者）

### 客户端状态管理

* [[Zustand]] — 极简、基于不可变快照且无需 Context 样板代码的微型状态管理库
* [[Jotai]] — 针对 React 深度设计的原子化（Atomic）细粒度响应式状态库
* [[Valtio]] — 基于 ES6 Proxy 的可变响应式编程体验状态工具
* [[Pinia]] — Vue 官方推荐的直观、轻量且天然类型安全的集中式 Store

### 通用工具与数据结构

* [[es-toolkit]] — 新一代高性能工具函数库，具备极小体积与原生 ESM/TypeScript 支持（Lodash 替代品）
* [[Radash]] — 现代语意化功能函数库，主打干净的 TypeScript 签名与无历史包袱
* [[Day.js]] — 仅 2KB 大小、API 完全兼容 Moment.js 的轻量级不可变日期时间处理库
* [[Immer]] — 基于写时复制（Copy-on-Write）实现可变写法维护不可变数据的核心库

### 交互动效与手势

* [[Framer Motion]] — React 顶级声明式弹簧物理动画与手势交互框架
* [[Motion One]] — 基于 Web Animations API 硬件加速驱动的超轻量跨框架动画库
* [[AutoAnimate]] — 单行代码实现 DOM 列表增删改平滑过渡的零配置动画工具

### 特色与小众生产力利器

* [[Lucide Icons]] — 现代设计风格、全面覆盖前端各框架的统一矢量图标系统
* [[Shiki]] — 基于 TextMate 语法树、支持精确现代语法高亮与 VS Code 级主题的美化引擎
* [[Sonner]] — 极具设计感与平滑堆叠动画的现代 Toast 消息通知浮窗库
* [[Rough.js]] — 基于 Canvas / SVG 实现手绘手稿手写涂鸦质感的图形库
