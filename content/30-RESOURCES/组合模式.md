## 术语：组合模式

> **主题**：#软件工程/设计模式

### 定义

**组合模式**（Composite Pattern）是一种结构型设计模式，将对象组织成树形结构，让客户端可以用相同的方式处理叶子节点和容器节点。核心在于定义了一个抽象组件接口，叶子和容器都实现该接口。

```typescript
abstract class FileSystemComponent {
  abstract getName(): string;
  abstract getSize(): number;
  abstract print(indent: string): void;
}

class File extends FileSystemComponent {
  constructor(private name: string, private size: number) { super(); }
  getName() { return this.name; }
  getSize() { return this.size; }
  print(indent: string) { console.log(`${indent}${this.name} (${this.size}KB)`); }
}

class Directory extends FileSystemComponent {
  private children: FileSystemComponent[] = [];
  constructor(private name: string) { super(); }
  getName() { return this.name; }
  add(child: FileSystemComponent) { this.children.push(child); }
  getSize() { return this.children.reduce((sum, c) => sum + c.getSize(), 0); }
  print(indent: string) {
    console.log(`${indent}[${this.name}]`);
    this.children.forEach(c => c.print(indent + '  '));
  }
}
```

### 跨学科含义

- **在前端开发中**：DOM 树是组合模式的经典体现——`Element` 和 `DocumentFragment` 都实现相同的 `Node` 接口，客户端可统一处理。React 组件树也是组合模式的应用。
- **在图形系统中**：绘图软件中的图形分组功能（Group 包含多个 Shape，Group 本身也是 Shape）。
