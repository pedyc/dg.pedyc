## 经过验证的高信噪比信源

> 一个信源 = 一张卡片（`30-RESOURCES/信源/`）。上方默认「总览」视图一眼看全评分、结论与评分时间（**已弃的源不列**）；切到「验证状态」看板可拖动卡片改状态，四列 = 候选 → 待验证 → 已验证 → 已弃；「五维明细」看单项得分。评分方法见 [[信源质量审计标准]]。
>
> 点开任意一张卡片，正文第一眼也是同一张「评分速览」表——它与本表、与 `.base` 的三处数字**同源**：都从卡片 frontmatter 实时算出，没有任何一处是手填的副本。所以你不会遇到"卡片显示 A 级、MOC 显示 B 级"这种不一致。

![[信源.base]]

## 怎么读这张表

| 列 | 含义 |
|:---|:---|
| 评分 | 五维（密度 / 时效 / 深度 / 独特性 / 产出率，各 1-5）之和，满分 25。**由公式算出，不手填** |
| 评级 | A 20-25 保留 / B 15-19 观察 / C 10-14 待砍 / D 5-9 立即砍 / **待评** = 五维未齐 |
| 状态 | 生命周期四态，见下节。`总览` 表只列未弃的源，`已弃` 只在看板里 |
| 结论 | 一句话采信方式。详细论证在卡片正文的「采信边界」段 |
| 评分时间 | 上次实际打分日期。**超过 4 个月未更新即视为过期**，审计时优先重评 |

「待评」不是坏数据，是**缺口标记**——它在提醒你这条源还在花时间消费，但价值没被验证过。

## 四种状态

看板按 `verify_status` 分四列。这是**一条生命周期，不是四个并列标签**：

| 状态 | 含义 | 怎么进 | 怎么出 |
|:---|:---|:---|:---|
| `候选` | 已记下，还没真正消费 | 被推荐、看到有人在用，先记一笔 | 开始订阅 → `待验证`；判断不值得看 → `已弃` |
| `待验证` | 正在消费，处于观察期 | 新订阅满 1 个月评估（SOP 场景 2） | 产出可追溯 → `已验证`；1 个月零产出 → `已弃` |
| `已验证` | 五维齐全且有实际 ingest | 观察期满通过 | 连续两季度掉到 B/C → 退回 `待验证`；退订 → `已弃` |
| `已弃` | 退订或放弃，**记录保留** | 判定不看 | 只在重新评估时回到 `候选` |

两条值得单独说：

- **`候选` 的评分就该是空的。** 没看过的源不该有分数，硬打分等于往数据里埋假样本。它们显示「待评」，而且正因为没分，在 `总览` 里一眼就能认出"这些还没验"。
- **`已弃` 不删卡片。** 卡片是历史基线：下次遇到同类源，你能查到当初为什么砍它、砍在第几轮。但 `已弃` 不参与 `总览`——否则清单只会越用越长，而"我该读什么"的答案反而越来越模糊。

## 五维评分测不出来的东西

五个维度量的全是**信息供给量**，没有一个在量**信息保真度**。

后果很具体：一个阴谋论源和一个立场型源，都能拿到 3 分左右的密度与深度、4 分的独特性，稳稳落在 B 级「观察」——但它们的真正风险不是"信噪比不够高"，而是"信号本身有系统性失真"。**用信噪比去筛失真的源，等于用音量去判断音准。**

所以每张卡片额外带一个**不可加权的定性标签** `source_risk`：

| 取值 | 含义 | 采信规则 |
|:---|:---|:---|
| `无` | 事实层可直接引用 | 按正常规则用 |
| `推演型` | 结论层脱离事实（脑洞、臆测、阴谋论），但内部逻辑自洽 | 只能当**假设种子**，写成 `question` 而不是 `atomic`；任何事实需独立验证 |
| `立场型` | 推理可靠，但**立场或叙事框架参与了取样与结论**：或只挑支持自己的案例（取样被裁剪），或素材真实而归因被叙事引导（框架先行） | 只能当**对立视角的对冲**，必须成对消费，不可作单一事实来源 |

它不是第六个评分维度——**不参与总分、不参与评级**，因为它回答的是另一个问题：**这条信息，我可以拿它来做什么。**

## 消费规则

- **产出率是唯一不设否决线的维度。** [[信源的产出率衡量的是转化效率而非信源价值]] ——一个源产出率为 0、却靠其余四维仍站上 A/B 级，恰恰反证它的价值不在被引用，而在**改变你的判断框架**。框架变了不会表现为新增笔记，但会让其余所有源变得更可用。这类源是视野补充，砍掉的代价远大于留着
- 反过来，低产出率 + 低总分，才是退订的完整证据：前者说明没转化，后者说明没料，两条同时成立才不冤
- 一个源的**价值上限不等于它读起来舒不舒服**：读着爽但既没转化也没改变判断的源，是最该砍的一类
- 打开卡片先看「采信边界」：✅ 可用的部分 / ⚠️ 约束条件 / ❌ 不可用的部分
- C 级源给 1 个月宽限期，到期不改善则自动退订，不重新讨论（见 [[信源质量审计标准]]）
- **退订的动作是把卡片拖到 `已弃`，不是删文件。** 删掉就没有基线了，下次遇到同类源还得从头踩一遍
- 状态迁移一律在「验证状态」看板里拖，不用手改 frontmatter——拖一次会回写一次
