## 概念： CSS

> CSS (Cascading Style Sheets) 是 Web 的表现层语言，通过层叠和继承机制决定 HTML 文档在屏幕、打印等媒介上的渲染方式。

---

### 定义

- **核心范畴**：样式语言、布局系统、视觉特效、工程化
- **不包括**：JavaScript 逻辑、后端样式处理
- **与相关领域的区别**：
	- vs HTML：HTML 结构 vs CSS 样式
	- vs JavaScript：声明式 vs 过程式
