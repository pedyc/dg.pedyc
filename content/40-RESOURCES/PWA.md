## 术语：PWA

> **领域**：#前端/网页开发

### 定义

PWA（Progressive Web App，渐进式网页应用）是一种结合 Web 与原生应用优势的网页开发技术，通过现代 Web API 和渐进式增强策略，提供接近原生应用体验的 Web 应用。

**核心特征**：
- **渐进式**：适用于所有浏览器，通过渐进增强为现代浏览器提供更好体验
- **响应式**：适配各种设备尺寸（桌面、移动、平板）
- **独立连接**：可在离线或弱网络环境下正常工作
- **类原生体验**：具有原生应用的交互和导航体验
- **持续更新**：通过 Service Worker 实现无缝更新，无需用户手动下载
- **安全**：仅在 HTTPS 环境下提供服务
- **可发现**：可被搜索引擎索引，也可通过 URL 分享
- **可安装**：用户可将应用添加到主屏幕
- **可重连**：无论何时何地都能访问

**核心技术**：
- **Service Worker**：实现离线缓存、后台同步
- **Web App Manifest**：定义应用的元数据（图标、主题色、启动画面）
- **Push API**：接收服务端推送通知
- **Cache API**：管理资源缓存

### 跨学科含义

- **在移动开发中**：PWA 是跨平台开发的方案之一，与 React Native、Flutter 不同，无需应用商店分发
- **在前端性能中**：通过缓存和预加载策略实现快速加载和离线访问
- **在用户体验中**：提供类似原生应用的首屏、导航和交互体验
