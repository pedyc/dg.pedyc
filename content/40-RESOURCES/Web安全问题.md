## 一、XSS 跨站脚本攻击

### 基础概念

- [ ] **什么是 XSS？有哪几种类型？**
	- → 存储型、反射型、DOM 型；
	- 追问：它们的区别是什么？哪个最危险？

- [ ] **XSS 的危害有哪些？**
	- → 会话劫持、账户接管、页面篡改、蠕虫传播

- [ ] **XSS 和 CSRF 有什么区别？**
	→ XSS 是 " 骗浏览器执行恶意代码 "，CSRF 是 " 借用户身份发请求 "

### 防御与场景

- [ ] **前端如何防范 XSS？**
	→ 转义输出、避免 v-html/CSP/输入验证；追问：React/Vue 的转义机制

- [ ] **innerHTML 和 innerText 的安全差异？**
	→ innerText 自动转义，innerHTML 不会

- [ ] **CSP 是如何防御 XSS 的？**
	→ 内容安全策略，限制脚本来源；追问：default-src、script-src 常用配置

- [ ] ** Cookie 的 HttpOnly 属性有什么作用？**
	→ 防止 JS 读取 Cookie，防御 XSS 后的会话劫持

### 关联

- 知识点详解：[[XSS]]、[[Web安全]]
- 延伸：CSP 配置参考

## 二、CSRF 跨站请求伪造

### 基础概念

- [ ] **什么是 CSRF？攻击条件是什么？**
	→ 利用登录态发送伪造请求；条件：用户登录、访问恶意页面、浏览器自动带 Cookie

- [ ] **CSRF 和 XSS 的核心区别？**
	→ XSS 在客户端执行恶意代码，CSRF 在服务端以用户身份发请求

- [ ] **为什么 GET 请求也会遭受 CSRF？**
	→ 浏览器会默认携带 Cookie，img/script/src 都会触发请求

### 防御与场景

- [ ] **如何防御 CSRF？**
	→ CSRF Token、SameSite Cookie、二次验证、Referer 检查

- [ ] **SameSite=Lax 和 SameSite=Strict 区别？**
	→ Strict 完全禁止跨站请求，Lax 允许导航类 GET 请求携带

- [ ] **前后端分离项目中，Token 放哪里？如何传递？**
	→ 放请求头（Authorization），而非 Cookie；追问：为什么不放在 URL 参数

- [ ] **为什么 Cookie 不能完全防止 CSRF？**
	→ Cookie 存储登录态，攻击者借用户身份发请求时浏览器会自动携带

### 关联

- 知识点详解：[[CSRF]]、[[Cookie 安全]]、[[Web安全]]

## 三、点击劫持

- [ ] **什么是点击劫持？如何防御？**
	→ 透明 iframe 覆盖页面诱导点击；防御：X-Frame-Options、CSP frame-ancestors、JS 检测顶层窗口

- [ ] **X-Frame-Options 和 CSP frame-ancestors 有什么区别？**
	→ 前者响应头只支持三个值，后者 CSP 指令更灵活

- [ ] **什么是拖拽劫持？**
	→ 诱导用户拖拽操作（如复制粘贴）获取内容

### 关联

- 知识点详解：[[点击劫持]]

## 四、HTTPS 与传输安全

- [ ] **HTTPS 的握手过程是怎样的？**
	→ TCP 三次握手 → TLS 1.2 四次握手（或 1.3 三次）→ 对称密钥交换

- [ ] **什么是 HSTS？有什么作用？**
	→ 强制浏览器使用 HTTPS，避免 HTTP 降级攻击

- [ ] **为什么需要证书锁定（Certificate Pinning）？**
	→ 防止中间人伪造证书

### 关联

- 知识点详解：[[HTTPS]]、[[TLS]]

## 五、综合场景题

- [ ] **用户输入内容要展示在页面上，如何防止 XSS？**
	→ 输入验证 + 输出转义 + CSP + 避免 innerHTML

- [ ] **如何设计一个安全的文件上传功能？**
	→ 文件类型白名单、大小限制、文件名随机化、存储分离、不执行上传目录

- [ ] **如何防止接口被恶意刷量？**
	→ 限流、验证码、IP 封禁、行为检测

- [ ] **你了解哪些 Web 安全攻击？如何在前端层面做防御？**
	→ 综合题，XSS/CSRF/点击劫持/中间人，按攻击类型展开
