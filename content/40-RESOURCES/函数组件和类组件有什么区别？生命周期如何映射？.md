## 问题

> 函数组件与类组件有什么区别？生命周期如何映射？

---

## 回答

### 函数组件与类组件有什么区别？

函数组件和类组件都是**声明式**的，这一点必须明确——两者都描述 "UI 应该是什么样子 "。

**函数组件**本质是一个普通的 JavaScript 函数，接收 props 并返回 React 元素（JSX）。在 Hooks 出现之前，函数组件只能做简单的展示，无法使用 state 和生命周期。React 16.8 引入 Hooks 后，函数组件获得了与类组件等价的能力。

**类组件**需要继承 `React.Component`，必须定义 `render()` 方法返回 JSX。类组件有自己的 `this` 上下文、独立的 `state` 状态对象，以及一系列生命周期方法。

两者的核心区别体现在以下几个方面：

**第一，状态管理方式不同**。类组件通过 `this.state` 和 `this.setState()` 管理状态，状态更新必须通过 `setState` 方法。函数组件通过 `useState` Hook 返回的数组管理状态，其中第一个元素是当前值，第二个是更新函数。

**第二，生命周期实现机制不同**。类组件有一系列生命周期方法如 `componentDidMount`、`componentDidUpdate`、`componentWillUnmount` 等。函数组件通过 `useEffect` Hook 模拟这些生命周期行为，通过依赖数组控制执行时机。

**第三，this 绑定方式不同**。类组件的方法需要手动绑定 this，或者使用箭头函数定义方法。函数组件不存在 this 问题，props 作为函数参数直接传递。

**第四，逻辑复用方式不同**。类组件通常使用高阶组件或 Render Props 模式复用逻辑，容易产生嵌套地狱。函数组件通过自定义 Hooks 复用逻辑，更直观也更灵活。

**第五，打包体积不同**。类组件因为需要继承完整的 `React.Component`，打包体积通常比函数组件大。

### 生命周期如何映射？

函数组件通过 `useEffect` Hook 模拟类组件的生命周期，其映射关系如下：

**`componentDidMount`** 对应 `useEffect(() => {}, [])`。空数组依赖表示只在首次渲染后执行一次，等效于挂载完成。

**`componentDidUpdate`** 对应 `useEffect(() => {}, [dep])`。当依赖项变化时会执行，等效于更新完成后。

**`componentWillUnmount`** 对应 `useEffect` 的 return 函数。在依赖数组为空时，return 的清理函数会在组件卸载前执行。

**`shouldComponentUpdate`** 可以通过 `React.memo()` 或 `useMemo()` 实现，控制组件是否需要重新渲染。

**`getDerivedStateFromProps`** 可以通过 `useState` 配合 `useEffect` 组合实现，根据 props 变化更新 state。

需要特别说明的是，`useEffect` 的依赖数组是理解映射的关键：空数组 `[]` 表示只在挂载时执行一次（等效于 mount + unmount 的反向）；有依赖 `[dep]` 时，每次 dep 变化都会触发（等效于 update）。
