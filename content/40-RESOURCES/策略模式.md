## 术语：策略模式

> **主题**：#软件工程/设计模式

### 定义

**策略模式**（Strategy Pattern）是一种行为型设计模式，将一组算法封装在独立的策略类中，使它们可以互相替换。客户端在运行时选择具体策略，无需修改代码即可扩展新的算法。核心是"将变化的部分封装起来"。

```typescript
interface SortStrategy {
  sort(data: number[]): number[];
}

class BubbleSortStrategy implements SortStrategy {
  sort(data: number[]): number[] {
    console.log('Bubble sort');
    return [...data].sort((a, b) => a - b);
  }
}

class QuickSortStrategy implements SortStrategy {
  sort(data: number[]): number[] {
    console.log('Quick sort');
    return [...data].sort((a, b) => a - b);
  }
}

class Sorter {
  constructor(private strategy: SortStrategy) {}
  setStrategy(strategy: SortStrategy) { this.strategy = strategy; }
  sort(data: number[]): number[] { return this.strategy.sort(data); }
}

// Usage
const sorter = new Sorter(new BubbleSortStrategy());
sorter.sort([3, 1, 2]);  // Bubble sort
sorter.setStrategy(new QuickSortStrategy());
sorter.sort([3, 1, 2]);  // Quick sort
```

### 跨学科含义

- **在前端开发中**：表单验证策略——不同的验证规则（邮箱、手机号、长度限制）封装为独立策略。动画缓动函数（easing functions）也是策略模式的应用。Vue 的 `watch` 选项中的不同处理方式。
- **在后端开发中**：认证策略（JWT / OAuth / Session）、支付策略（支付宝 / 微信 / PayPal）、序列化策略（JSON / XML / Protobuf）。
