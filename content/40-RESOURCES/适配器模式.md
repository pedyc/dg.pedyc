## 术语：适配器模式

> **主题**：#软件工程/设计模式

### 定义

**适配器模式**（Adapter Pattern）是一种结构型设计模式，通过一个适配器类将不兼容的接口转换为目标接口，使原本因接口不匹配而无法协作的类可以一起工作。有两种实现方式：

- **类适配器**：通过多重继承（或 extends + implements）适配
- **对象适配器**：通过组合持有被适配者的引用（更灵活，推荐方式）

```typescript
// 目标接口
interface USBTypeC {
  charge(): string;
}

// 被适配者（旧接口）
class MicroUSB {
  oldCharge() { return 'Charging via Micro USB'; }
}

// 适配器
class MicroUSBToTypeCAdapter implements USBTypeC {
  constructor(private microUSB: MicroUSB) {}
  charge() { return this.microUSB.oldCharge(); }
}

// 客户端
const adapter = new MicroUSBToTypeCAdapter(new MicroUSB());
adapter.charge(); // "Charging via Micro USB"
```

### 跨学科含义

- **在前端开发中**：API 数据格式适配——后端返回的数据结构不符合前端需求时，通过适配器函数转换。Vue 的 `computed` 可以看作数据适配器。Axios 的适配器模式允许在不同环境（浏览器 XHR / Node http）使用统一 API。
- **在跨平台开发中**：React Native 的 `Platform.OS` 适配不同平台 API，本质上也是适配器思想。
