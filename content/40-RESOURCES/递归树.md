> 递归树是递归函数调用展开后形成的树形结构，每个节点代表一次递归调用

---

## 定义

递归树（Recursion Tree）是**递归算法的时间复杂度分析工具**，将递归调用展开为树形结构：

- **根节点**：原始问题的输入规模 n
- **叶子节点**：递归触底时的基本情况
- **内部节点**：子问题的输入规模

---

## 核心特点

| 特点 | 说明 |
|:---|:---|
| **树形展开** | 每个递归调用展开为子节点 |
| **规模递减** | 子问题规模逐层减小 |
| **触底终止** | 到达基本情况时停止递归 |
| **求和分析** | 每层代价之和即为总代价 |

---

## 应用场景

**递归树分析法**常用于分析以下递归算法的时间复杂度：

- **归并排序**：T(n) = 2T(n/2) + n
- **二分查找**：T(n) = T(n/2) + O(1)
- **快速排序**：T(n) = T(n/9) + T(9n/10) + n
- **树形遍历**：深度优先/广度优先的递归实现

---

## 示例：归并排序递归树

```bash
归并排序 T(n) = 2T(n/2) + n

层1:                    n
                      /    \
层2:               n/2       n/2
                  /   \     /    \
层3:            n/4   n/4  n/4   n/4
                 ...     ...
叶子:             1  1  1  1  1  1  1  1

每层代价: n + n + n + ... + n (log n 层)
总代价: n * log n
```

## 相关概念

- **递归**：函数自身调用自身
- **时间复杂度**：算法执行时间与输入规模的关系
- **空间复杂度**：算法占用内存与输入规模的关系
- **递归栈**：调用栈帧的栈结构
- [[Fiber架构(React)|React Fiber]]：React 中用链表代替递归树结构
