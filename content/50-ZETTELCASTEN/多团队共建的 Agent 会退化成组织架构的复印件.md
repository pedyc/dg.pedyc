> 多个团队共建一个 agent 时，若按团队边界切分子代理，架构必然变成组织架构的复印件——这是 Conway 定律在 agent 设计上的直接投影。

**边界**：只在「每个能力各有 owner 团队」的组织里成立。单人项目不会这样退化，但也因此容易犯反方向的错：该拆不拆，把并行与上下文隔离的收益一起放弃。

## 论据/示例

一家公司的客服 agent 里塞了来自不同团队的十几个专家子代理，结果是品牌一致性难以维持、延迟上升；同时每个团队往 system prompt 里加一句，最终形成互相冲突的 Frankenprompt，各自的 eval 只对自己的子任务过拟合、无人维护全集，管理层拿到的分数因此偏乐观。
