> 宏是一种编译时处理的语法糖，源码中写的是 A，编译器实际处理的是 B，运行时不存在宏的调用开销

## 论据/示例

**Vue 的 `defineProps()` 宏**：

```vue
<script setup>
	// 用户写的代码
	const props = defineProps({ name: String })
</script>
```

编译后实际变成（编译器重写）：

```javascript
const props = defineProps({ name: String })
// 无需 import，编译器自动识别
```

**与普通函数的区别**：

| | 普通函数 | 宏 |
|:---|:---|:---|
| 调用时机 | 运行时 | 编译时 |
| 打包结果 | 包含在 JS bundle | 被移除或转换 |
| 需要 import | 需要 | 不需要 |

**Vue 中的宏**：
- `defineProps()` — 编译时处理 props 声明
- `defineEmits()` — 编译时处理 emits 声明
- `defineExpose()` — 编译时处理暴露属性
- `withDefaults()` — 编译时处理默认值

**其他语言中的宏**：
- C/C++ `#define` — 文本替换
- Rust `macro_rules!` — 语法展开
- TypeScript 装饰器（实验性）— 编译时处理
