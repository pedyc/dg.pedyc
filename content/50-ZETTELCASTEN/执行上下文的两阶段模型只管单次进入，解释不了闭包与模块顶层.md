> 两阶段模型描述的是**一次进入**执行上下文的过程：创建阶段建立变量对象与 this 绑定，执行阶段逐行求值。它管不到「上下文已经离开、变量却还活着」这种情形——闭包与模块顶层就是这样，它们的生命周期不落在这两个阶段里。

**边界**：这是对单次进入执行上下文的分段描述。跨上下文的部分——闭包、模块顶层、事件回调——生命周期不在这两个阶段里，用两阶段模型解释它们会得出错误结论。

## 论据/示例

**创建阶段**：
- 确定 `this` 的值（this 绑定）
- 创建词法环境（LexicalEnvironment）
- 创建变量环境（VariableEnvironment）
- 扫描代码，进行函数声明和变量声明提升

**执行阶段**：
- 逐行执行代码
- 赋值语句修改变量值
- 执行函数调用

```javascript
console.log(a); // undefined（创建阶段已声明）
var a = 1;
console.log(a); // 1（执行阶段已赋值）
```
