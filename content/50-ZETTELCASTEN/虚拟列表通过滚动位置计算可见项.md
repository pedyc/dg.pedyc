> 虚拟列表通过滚动位置计算可见项——监听 scroll 事件，用 `scrollTop / itemHeight` 算出起始索引，再结合容器可视高度算出终止索引，只渲染这个范围内的数据。

## 论据/示例

```js
// 基础公式：滚动偏移 ÷ 每项高度 = 隐藏了多少项
const startIndex = Math.floor(scrollTop / itemHeight)
const endIndex = startIndex + Math.ceil(clientHeight / itemHeight)

// 总高度 = 数据总量 × 每项高度（用于撑开滚动条）
const totalHeight = data.length * itemHeight

// 偏移占位 = startIndex × itemHeight（让未渲染的项占据视觉位置）
const offsetY = startIndex * itemHeight
```

三种实现策略对比：

| 策略 | 计算方式 | 适用场景 |
|------|----------|----------|
| 固定高度 | `startIndex = floor(scrollTop / fixedH)` | 最简单，性能最好 |
| 动态高度（预估） | 先给默认值，渲染后测量真实高度缓存 | 内容高度可变 |
| 动态高度（绝对定位） | 每项 absolute + top 定位，无占位 | 极致的可变高度场景 |
