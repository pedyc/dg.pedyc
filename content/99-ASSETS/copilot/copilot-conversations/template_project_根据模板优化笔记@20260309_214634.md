## 🚀 SOP：滑动窗口解题法

### 🎯 目标与触发条件 (Goal & Trigger)

> [!summary]
> **触发场景**：当需要解决 **子串/子数组** 相关问题时，特别是涉及 **连续区间**、**满足特定条件的最长/最短子串**、**定长子串统计** 等场景。
> **预期结果**：将 $O(n^2)$ 的暴力解法优化为 $O(n)$ 或 $O(n \log n)$ 的高效解法。

### 🛠 前置准备 (Mise-en-place)

- [ ] **工具**: JavaScript (或你熟悉的编程语言)
- [ ] **素材**: 理解数组/字符串的基本操作，了解哈希表(Map/Set)的使用
- [ ] **心态**: 接受第一次可能写不出完美代码，重点是理解 **窗口扩张与收缩** 的思维模型

### 🪜 核心流程 (The Workflow)

#### 阶段一：初始化与定义

1. **定义变量**
   - `left = 0` (窗口左边界)
   - `right = 0` (窗口右边界，通常作为循环索引)
   - `window = {}` 或 `new Map()` (记录窗口内元素状态)
   - `result = 0` 或 `[]` (存储最终结果)
   - `valid = 0` (记录窗口满足条件的程度)

2. **确定循环结构**
   ```javascript
   while (right < s.length) {
       // 扩张窗口
       // 更新窗口状态
       
       // 收缩窗口 (内层while)
       while (窗口需要收缩的条件) {
           // 更新结果
           // 移动左边界
       }
       
       right++;
   }
   ```

#### 阶段二：扩张窗口 (右指针移动)

3. **将右指针元素加入窗口**
   ```javascript
   let c = s[right];
   // 更新window[c]的计数或状态
   ```

4. **检查窗口状态是否满足条件**
   - 如果是**寻找最小窗口**：在内层while中收缩
   - 如果是**寻找最大窗口**：在外层更新结果

#### 阶段三：收缩窗口 (左指针移动)

5. **当窗口不满足条件时收缩**
   ```javascript
   while (需要收缩的条件，如：window中某元素计数 > 1) {
       // 更新结果（如果是找最小窗口）
       result = Math.min(result, right - left + 1);
       
       // 移出左指针元素
       let d = s[left];
       // 更新window[d]的状态
       left++;
   }
   ```

#### 阶段四：更新结果

6. **在合适的位置记录答案**
   - **找最大窗口**：在收缩前或外层循环结束时更新
   - **找最小窗口**：在收缩过程中更新

### ⚠️ 常见坑点与排错 (Troubleshooting)

- ⛔ **反模式**: 在收缩窗口时忘记更新 `window` 状态，导致状态不一致
- ⛔ **反模式**: 左右指针移动顺序错误，导致漏算或重复计算
- 🔧 **故障排查**:
  - 如果遇到 **无限循环**：检查收缩条件是否可能永远为真
  - 如果遇到 **结果错误**：添加 `console.log` 打印 `left`、`right`、`window` 状态，逐步调试
  - 如果遇到 **边界错误**：特别注意 `right-left+1` 与 `right-left` 的区别（包含右端点与否）

### 🧬 原理与优化

- **底层逻辑**: 本流程基于 **双指针** 和 **哈希表** 的原理设计，通过维护一个动态窗口，避免重复计算。
- **时间复杂度**: 每个元素最多被右指针访问一次，被左指针访问一次，因此是 $O(2n) \approx O(n)$。
- **空间复杂度**: 使用哈希表存储窗口状态，最坏情况 $O(k)$，其中 $k$ 是字符集大小。

#### 优化日志
- **2026-03-09**: 初版建立，总结自 [[P-算法提升专项]] 中的滑动窗口题型练习
- **待优化**: 增加更多变体示例（固定窗口大小 vs 可变窗口大小）

### 📚 经典例题

1. **无重复字符的最长子串** (可变窗口，找最大)
   - 关键：用Set记录窗口内字符，遇到重复时收缩
   
2. **最小覆盖子串** (可变窗口，找最小)
   - 关键：用Map记录目标字符需求，valid计数判断是否覆盖
   
3. **找到字符串中所有字母异位词** (固定窗口)
   - 关键：窗口大小固定为p的长度，比较窗口与p的字符频率
