## ⚙️ 工具：Claude Code

### 🎯 核心功能 (Core Function)

> [!abstract]
> Claude Code 是一个专为开发者设计的命令行工具，将 Claude 模型的代码生成、解释和调试能力无缝集成到终端工作流中。

### 🛠️ 使用场景 (Use Cases)

- **快速代码生成**：在终端中直接生成代码片段或函数。
- **代码解释与调试**：粘贴一段代码，让 Claude 解释其逻辑或找出潜在问题。
- **Shell 命令生成**：用自然语言描述任务，生成对应的 Shell 命令。
- **文件内容分析**：直接读取本地代码文件并提供改进建议。

### 📦 安装与配置 (Setup)

```bash
# 安装方式 (示例，请以官方文档为准)
npm install -g @anthropic-ai/claude-code
# 或
curl -fsSL https://cli.anthropic.com/install.sh | sh
```

**配置步骤**：
1. 获取 Anthropic API Key。
2. 运行 `claude auth` 进行认证。
3. 设置默认模型和参数（可选）。

### 🔧 常用命令示例 (Examples)

```bash
# 生成一个 Python 函数
claude code "写一个用递归计算斐波那契数列的Python函数"

# 解释一段代码
claude explain path/to/your/file.js

# 与本地文件交互
cat complex_script.py | claude debug
```
