	学习专项子模板：三节必填，其余按需（2026-11-08 重写）。

	**为什么只有三节**：上一版把同一条 KR 写在三处——战略地图、排期表、验收表。
	改一处要同步两处，不同步不报错，只让读者不知道该信哪个。现在 KR 只出现一次。

	**三节各管一件事**：
	- 目标：学完能回答哪一类问题，以及不学什么。范围边界比目标更能防膨胀——
	  学习专项很少死于目标不清，多死于把「跑通一次」做成「铺满每层」。
	- 成功标准：一行一个 KR，同时写判据与验法。判据是「达成是什么样」，
	  验法是「谁来验、怎么验、答不出什么就算没过」。学习专项的验法默认是费曼：
	  凭记忆讲给不懂这个领域的人——拿稿讲等于没讲。
	- 进展：在哪、卡在哪、下次坐下第一件事做什么。不写百分比，进度由结果列的「过 / 未过」数。

	**费曼为什么只是一列，不是一节**：它回答的正是「这一行怎么算过」。独立成节会让
	KR 再抄一遍；而它不该写进复盘的理由仍然成立——复盘随项目归档退役，费曼的缺口
	必须变成红链留下来，所以「卡在哪 → 缺的 atomic」是这张表唯一必须落到链接的列。

	**验你的人不是裁判**：另起一个会话当对手时，它只读得到这张表。所以判据要写成
	它能机械比对的形式——漏一个要点、或答不出那条反例，即判未过。它天然顺着人说，
	「讲得通」会被判成「掌握了」，这正是 [[费曼技巧]] 的失效边界。

	**复查不在这一页**：复查对象是表里那批 atomic，进 Anki 后由调度决定到期
	（口径见 `_anki-sync-rules`：atomic → recall 卡）。在这里排日期等于手抄一份复习计划。

	**扩展开关**——不满足条件就别加，加了会空着：

	| 什么时候才加 | 加什么 |
	|:--|:--|
	| 动机不是显而易见（不学也不会马上出事） | 「目标」前加「背景」：只写不做的后果，不写来历 |
	| 阅读顺序超过三步，且顺序决定先学什么 | 「学习路径」：阶段 / 读什么 / 自测，排在成功标准之后 |
	| 知识点散落在库里，要追状态 | 「知识点台账」：阶段 / 知识点 / 形态 / 状态 / 链接，状态只有已有、待写、断链 |
	| 有 KR 要求「真跑一次」，或依赖账号、仓库、素材、硬件 | 「执行环境」：跑在哪、用什么、发到哪，分已定 / 待确认 |
	| 有硬期限，`expire` 要拆到阶段 | 「排期」：写最晚开始，不写计划开始 |
