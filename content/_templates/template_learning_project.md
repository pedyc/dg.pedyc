	判据：
	1. 先画链再写目标。链 = 一份产出的生命周期 / 每步要下的判断 / 判错的代价。第三列填不出的
	   不是环节，是知识点，挪去 atomic。链即范围，链外的概念自动出局。
	2. 切不出链就别开专项（能力集合没有生命周期），那是 concept + MOC 的事。
	3. 产出是链上缺的那一块：节点 → atomic、动作 → sop、骨架 → concept 的节点增删与优先级修正
	   （无新文件，最易漏记）、断链 → 旧条目修好或判为不修。sop 准入：步骤多到下次会忘且还要再做。
	4. 不用 template_project 的战略地图：项目依赖 ≠ 理解依赖，两者可以相反。只留理解顺序（即链）；
	   排期与先做哪件写进学习路径的阶段格，不另立表。
	5. KR 与环节不必一一对应：链是逐点分解，KR 是跨环节抽样，个数本不该相等；KR 也不该把链的每一行
	   改写一遍，那等于换个地方重抄链。目标节只写代价与范围，出现「能讲出 / 说得出」一类的动词就是越界。

	7. 不排复查（atomic 进 Anki，见 `_anki-sync-rules`）；不设知识点台账（是末列的派生视图，
